An Image's, a Quote's and a Section's block style tiles in the Style tab now draw the block itself in each style. An Image shows its own picture as Square, Rounded and Circle (a picture's outline while it has none), a Quote shows its own words as Line, Plain and Large, and a Section shows a band of the page as Plain and Hero, in place of the colour swatches and the dashed "Section" box. Each is drawn at the page's own sizes and scaled down, so a Hero's height and a Large quote's size read in proportion. The rows in Design's Block styles draw the same samples.
