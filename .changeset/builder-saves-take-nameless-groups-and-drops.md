A Schema Builder collection whose group holds a group with no name, which only lays its fields out, saves again. The definition file now accepts a group without a name; every other field still needs one.

A Schema Builder field change that removes a field and fills a new required field over existing rows in the same save is no longer refused with "destructive_drop:… is not a change to a field of this collection". The drop's confirmation is now matched against the fields the collection had before the save.
