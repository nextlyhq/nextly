The dashboard draws what plugins add to it (experimental).

- Its blocks stand around the page's own two, the welcome header (`welcome`) and the grid of cards (`widgets`), in the order sent, each behind its own error boundary. A block placed by nothing goes below the grid; one with `before: "widgets"` (or `after: "welcome"`) goes between the header and the cards.
- The grid is each person's own arrangement of their cards, so a plugin may place a block beside it but not replace it: startup refuses a `replaces: "widgets"`, naming the plugin and the contribution (`contribution-replace-not-allowed`). The welcome header may be replaced.
- A dashboard with nothing contributed is unchanged.
