Restoring unsaved work from a recovery point in the Page Builder is now one step you can undo: Undo puts the stored page back, and Redo the recovered one. The other fields from the recovery point are restored as before. Plugin authors get `useDocumentRestore` from `@nextlyhq/plugin-sdk/admin` (experimental), with which a document view restores its own field as an edit of its own; a view that doesn't register one is restored as before. The editor's save state is set in the top bar's text size.
