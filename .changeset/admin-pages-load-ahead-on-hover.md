Admin pages open faster after a hover. Pointing at a link, focusing it with the keyboard or touching it now starts loading that page's code, so the click usually finds it ready. Downloads and links to other sites are left alone. While a page's code is still loading, the spinner appears only after 200 ms, so a fast load no longer flashes it. Screen readers still hear "Loading" straight away. If a page's code fails to load, the error is written to the browser console and a later visit tries again.
