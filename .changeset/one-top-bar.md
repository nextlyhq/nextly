The admin draws one top bar, 56px tall at every width. Each page's breadcrumb is in it, and on a bar narrower than 600px it shortens to a back link named by the parent page. Below 1024px the bar holds the menu button that opens the navigation drawer, so a phone gets one bar instead of two. A page can put its own actions at the bar's right end. The bar's height is the CSS variable `--admin-bar-height` on `.nextly-admin`, which the editors and full-height pages read.
