`nextly repair-columns` names the right cause for a Single's required relationship or upload held `NOT NULL`. The report said "created by the current version's generator", which would make the column again after a repair; the Schema Builder has left it nullable since 0.0.2-alpha.79, so the line now says "created before 0.0.2-alpha.79". A Single the Schema Builder made and code declares now, whose line gave no cause, says the same. In `--json`, such a column's `cause` is `legacy` with the new shape `single-required-reference`. What is reported and converted is unchanged.
