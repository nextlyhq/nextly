The SEO plugin's problems show in the page builder's Page checks, under Search. While you edit a page, Page checks lists the problems the SEO problem list shows you for that page and language, in the list's own words. A problem fixed in the page's SEO tab opens the builder's SEO tab of Page settings. The list is read as you: a page you may not read is never compared with yours, and a redirect problem stays on the problem list. The items follow the page's last save, when the SEO plugin checks it again.
