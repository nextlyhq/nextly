`nextly prune` lets go of the columns a plugin field keeps on a type the site switched off. It lists them with everything else it would drop, under the same data-loss consent. A site without migration files has them dropped from its database; a site with migration files gets a migration that drops them, so every environment drops them at its next `nextly migrate`.
