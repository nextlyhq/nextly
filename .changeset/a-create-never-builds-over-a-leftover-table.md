A field-group or Single create no longer builds over a table that already stands under its name with nothing registered describing it. An empty one is replaced, so the table ends up with exactly the requested columns. One holding rows is refused, naming each table and how many rows it holds, and is left as it was. A create is also recorded as applied only once its table holds every requested column with the requested type; otherwise it is recorded as failed. A create of a field group whose name is already taken is refused naming that name. Collection creates keep their current behaviour for now.
