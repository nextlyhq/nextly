A design token file stays valid DTCG 2025.10 when a text style scales a variable. A scaled part is now typed as its part types a plain value, so a size scaled from a number variable, a line height scaled from a size variable or a weight scaled past 1000 is no longer written as an invalid typography value: that text style is kept as Nextly data only and listed under "What wasn't exported", and a Nextly import reads it back exactly. A font weight outside 1 to 1000 is no longer written as a DTCG weight.
