The editor's top bar reports a stored page as Saved from the moment it opens, with when in the tooltip, and its save state stays on one line (the search's key hint gives way first). Unsaved work from a recovery point is offered in the save chip, with Restore and Not now, instead of a banner above the editor; a plugin's document view that draws no save chip keeps the banner. In the Pages panel, a draft can be duplicated, and a page with newer unpublished changes says its copy is the published version. Getting started shows only on a page that opens empty, above the canvas's overlays, remembers its dismissal per author, and counts text as written only when it isn't the block's starting text.
