A code-first collection whose `dbName` moves it to a table that is already there is refused
at start and by `db:sync`, naming both tables, and keeps its old table: before, the sync only
warned and recorded the new table, so the collection was served from a table that did not
hold its entries. The same holds when the database refuses the table rename, or the tables
cannot be read to decide. The collection is reported among the ones not set up, and serves
from its old table until the configuration or the tables are put right.
