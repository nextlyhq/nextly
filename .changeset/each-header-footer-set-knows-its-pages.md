Page builder: a new route, `GET /layouts/counts`, answers how many pages use each header & footer set the caller may read. A set counts the pages that name it; the site default also counts the pages that follow it and those falling back to it from an unpublished set. Pages the caller may not read count as a number only, and a count reads "at least N" (`floor: true`) when a bounded read stops early.
