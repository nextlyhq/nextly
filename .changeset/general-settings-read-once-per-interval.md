The general settings row (site name, address, logo, time zone, sidebar groups) is now read at most once every 2 seconds by each server copy, with one read shared by every request that arrives meanwhile, instead of once for every API answer: an entry's edit screen read it 22 times, and now reads it once. A change saved through the copy that serves the save is seen there at once; one saved through another copy is seen within 2 seconds. Preview links are the exception: their revocation generation and the site address they send their holder to are read from the database on every mint, verification and redirect, so a revoke or a new address saved anywhere applies at once.
