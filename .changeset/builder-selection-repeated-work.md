Selecting a block in the page builder does less repeated work on a large page. The breadcrumb and the selected block's toolbar and keyboard verbs share one Layers tree per page rather than each building its own, the getting-started steps are worked out once per page rather than on every click, and the admin's check for whether an entry is a Single reads the cache only when that answer changes.
