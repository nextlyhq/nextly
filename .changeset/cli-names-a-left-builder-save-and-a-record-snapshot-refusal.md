Two refusals that commands ended with under the wrong code now print a code of their own. `nextly migrate:create --record-snapshot` with table changes to migrate ends as `RECORD_SNAPSHOT_HAS_CHANGES` instead of `CONFIG_INVALID`, which told you to fix declarations in `nextly.config.ts` that were not wrong. A Schema Builder save left part-way, and a save record that cannot be read, end as `BUILDER_SAVE_LEFT_PART_WAY` instead of an unexpected error. Each code has a docs page under `/docs/cli/errors`.
