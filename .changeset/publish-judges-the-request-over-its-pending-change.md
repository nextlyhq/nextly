Publishing one language of a localized Single whose pending change is behind newer shared values now succeeds when the publish request itself sends the live value of each field the change is behind on. The change is judged as the publish writes it, with the request merged over it. Before, the publish was refused as out of date, and the request had to be split into taking the live values first and then publishing.
