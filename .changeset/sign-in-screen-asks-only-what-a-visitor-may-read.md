The admin's sign-in screen no longer asks for the general settings or the workspace half of the admin metadata while nobody is signed in. Both are only answered to a signed-in session, so a visitor's request could only be refused (401), and each was sometimes sent twice: a refused query is asked again by every part of the screen that mounts after the refusal arrives. The sign-in screen now sends two requests instead of four, and draws the same public branding as before, from the public half of the admin metadata and what the device remembered. Signed in, each is asked once, as before.
