A save with no status, made while another editor's draft is pending, now keeps that draft's value of each group field the saver may not write. Before, the save put the live value back there, which undid the other editor's pending edit. The rest of the group is saved as sent. If the saver sends a value for such a field that is neither the live value nor the pending one, the save is refused with `FORBIDDEN`, naming the field, and nothing is written.
