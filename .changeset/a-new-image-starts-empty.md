A new Image no longer points at a missing example file. On the canvas it draws an empty box, 16:9 until the block sets its own proportion, reading "Add an image" with Upload, Media library and Link, and a picture file can be dropped on it or on an Image that has one; the upload goes to the media library with its progress on the block. A link is kept only once it loads as a picture, and an Image whose library file was deleted says so with Replace. On the published page an Image with no picture draws nothing. In the media library picker, a click anywhere on a tile chooses it, and in a single pick a double-click picks it and closes.
