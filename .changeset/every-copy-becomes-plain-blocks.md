`@nextlyhq/blocks-engine` adds `inlineComponentInstances`, which turns every copy of one component in a document into the plain blocks it draws, and `stillReferences`, which says whether a document still references a component (`"yes"`, `"no"` or `"unknown"`). Both are `@experimental`. A conversion that could not keep the document as it rendered is refused and changes nothing: a copy the detach planner refuses, a copy standing in a locked slot it would break, a node a host component exposes, a variant or override that installs the component, or a document that cannot be read to the end.
