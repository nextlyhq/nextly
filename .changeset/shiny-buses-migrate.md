`nextly migrate:baseline` now compiles the app's extension schema, as `migrate:create` and `migrate:check` already do. Adopting a database built by `db:sync` records the tables an app declared through `db.schema.extend` and names the elements it contributed to other owners' tables, so the first `migrate:create` after graduating no longer re-creates a table that is already standing or re-emits an index the database already has.
