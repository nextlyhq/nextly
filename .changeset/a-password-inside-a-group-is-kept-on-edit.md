A password inside a group is kept when an edit doesn't resend it. An update that leaves out, or sends empty, a password held in a group or repeater, or in a field group held inline in one, keeps its stored hash; `null` still clears it and a new value replaces it. Repeater rows keep their own by id, and a translated group keeps the written language's.
