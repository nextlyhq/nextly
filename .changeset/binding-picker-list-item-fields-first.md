In the page builder, a block inside a collection list now finds the list item's own fields first in its data picker ("Each post"), before This page, Singles and Site, so binding a heading to Title shows each entry's own title instead of the page's title on every row. The field bound now is marked when the picker opens again. Each item field shows its value from the list's first entry, and a draft's value is shown with "Draft" beside it instead of the word alone; a reader who can't edit the entry still sees only the published value. `@nextlyhq/blocks-react/blocks` now exports `readList` (experimental) for reading a list's entries the way the list block does.
