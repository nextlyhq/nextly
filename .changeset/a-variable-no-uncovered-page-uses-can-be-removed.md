A variable that no page uses can now be removed on a site whose usage count cannot become whole. When some pages are too large to read in full, or keep their blocks in a field nested under a named group, the removal reads just those pages for the variable's stored reference. If none of them uses it, the removal goes ahead. If one does, the removal is refused and that page is named. A page that cannot be read within the removal's time is also refused and named. Before, every variable removal on such a site was refused, whether the variable was used or not.
