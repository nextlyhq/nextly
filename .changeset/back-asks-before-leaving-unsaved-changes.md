Going Back or Forward from a document with unsaved changes asks before leaving again on an app rendered with Cache Components. There the admin's code arrives after Next's router has started listening for Back, so the router moved to the page Back was going to before the admin was asked, and the changes were lost without a word. Where the browser lets a page cancel Back (it does once the reader has used the page), the admin now cancels it before it moves and asks; where it does not, or where the browser has no Navigation API, it asks as before. Nothing changes for an app without Cache Components, and a Back with nothing unsaved is never touched.
