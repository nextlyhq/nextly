`@nextlyhq/plugin-seo` no longer asks to confirm, or lists as problems, robots.txt blocks on a site that serves its own robots.txt file, since the plugin's rules are not the ones crawlers read there. An `Allow` exception to a rule closing the whole site is judged by every page it can open, so a partial policy is no longer refused because a few sample pages happened to be closed.
