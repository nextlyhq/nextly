A Single schema save whose change reached the database but could not be recorded applied now fails, saying so. It names the migration file kept for the change and the steps that finish it: check or finish the change by hand, run `nextly migrate:resolve --applied` with that file, then run `nextly migrate`, which brings the registry in step. The Single keeps the fields it had recorded until then. It used to record the requested fields with the status "failed" and answer that the migration was pending.
