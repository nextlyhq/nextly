The admin downloads less on every screen and ships less in total. The licence banners its bundled packages carried in every chunk (one per icon, from the icon set) are replaced by a single `THIRD-PARTY-NOTICES` file in the package, holding each bundled package's own licence text. `tailwind-merge`, `clsx`, `class-variance-authority` and the Radix primitives are no longer bundled into the admin: `@nextlyhq/ui` depends on them at the same ranges, so an app's build now ships one copy of each instead of two. In a production build of an app with a plugin page, the admin's first load falls by about 10 KB (gzipped).
