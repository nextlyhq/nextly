A hook on an update made inside a transaction (a plugin's
`updateEntryInTransaction`, a batch) is handed the entry with its translated
values, as an update made outside one is, so a hook reading a translated
field such as the title finds it. A sort on an untranslated collection's text
orders an empty string as a value again, and a Single read with `select`
carries the same version a full read does, so a check comparing the two sees
a change saved in the same second.
