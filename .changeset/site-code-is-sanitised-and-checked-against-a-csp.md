The page builder can now judge site code before it is stored: `sanitiseSiteCode` turns pasted HTML into entries a published page can carry in its head or at the end of its body (scripts, styles, meta tags, links and a no-script pixel), refusing with a reason anything that hides code in markup, loads from anywhere but `https:` or the site itself, or would break out of its place. `checkSiteCodeAgainstCsp` says which entries the site's Content Security Policy would block, and `mergeSiteCodeIntoCsp` adds what the code needs to a policy without widening anything else it allows. These are experimental until site code renders.
