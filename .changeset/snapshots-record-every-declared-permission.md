Every migration snapshot now records every permission the configuration declares, by owner: each collection's and Single's built-in and workflow permissions, the app's own, and each installed plugin's. It records no grant. When the only change since the newest snapshot is to an app's or a plugin's declared permissions, `nextly migrate:create` writes a migration with no table statements that names the plugin and each permission it adds or removes. The first `migrate:create` after upgrading writes one migration recording every entity's settings and every declared permission; a snapshot written before this records nothing about permissions and is never read as permissions removed.
