Leaving a text box in the page builder's side panel, for example by clicking Save straight from it, no longer says the change could not be saved because the page is at its size limit when it was saved, and Save now turns to Saved. When a change really cannot be saved, the box says why: the size limit only when the page is at it, or that the text can no longer be changed. Pressing Escape then also takes the typed words off the page, so the canvas matches the box.
