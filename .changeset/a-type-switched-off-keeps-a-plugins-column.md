A type a site switches off for a plugin's field (`except` in a `contributes.extend` scope) after the field's column was made keeps the column and the values in it. The field stops showing in the API, the admin and the outputs, and an entry saved while the type is off needs no value for it; switch the type on again and the saved values are back. Dev push, `nextly migrate:create` and `nextly migrate:check` keep the column rather than planning or reporting its drop, for types in the configuration and types made in the Schema Builder. A type switched off before its first migration still never gets the column.
