A filter on a localized date field now compares as the instant it names, on every dialect. The companion `EXISTS` bound the operand raw, so on SQLite an integer epoch column compared with a text parameter and type ordering answered instead of time — a "later than" filter matched entries it should not, and a bulk update or bulk delete by that filter acted on the wrong documents, while PostgreSQL and MySQL each read the same operand alone. The localized builder now resolves the companion column and reads date operands through the same strict reader the main where builder uses; an operand no date can read is refused with the answer the main filter gives, where before each dialect decided by itself.
