The style editor shows a block style with the same State switch a block's Style tab has: Normal, Hover, Focus and Pressed, with a dot on each state that holds values. It also names the device the top bar edits, so a style's hover and other states can be set at each device. While a state other than Normal is chosen, the controls sit on that state's tint, under the line that says so.

The editor says what an edit to a block style reaches: "Changes every Button using Ghost on every page". The block's own style still says that it changes every block of its type.
