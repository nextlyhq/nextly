A written email template can be converted to code (`@experimental`): saving `format: "code"` on it, through the ordinary update, keeps exactly the Liquid its blocks compile to, chips, conditions and lists included, so it sends the same email, and from then on it is edited as code. The conversion is one way: a coded template is never turned back into blocks.
