A block inside a list that sits inside another list can show the outer list's entry. The data picker lists every enclosing list's entries, nearest first ("Each project in the list", then "Each category in the list"). A field picked from an outer list stores which list it reads (an item binding's new `list`, `@experimental`), and the canvas and published pages fill it from that list's entry. A save refuses a binding naming a list the block is not inside.
