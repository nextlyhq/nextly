Forms can take one response per browser. The form's script keeps a random token in the visitor's browser and sends it as the `nextly-browser-token` answer; the server keys it with the plugin's keyed digest, never stores the token, and refuses a second response from the same browser atomically. The public read of a form that compares browsers names the answer to send the token in (`oneResponse`). A submission without a token is accepted unchecked, with a warning. Settings offers "One per browser".
