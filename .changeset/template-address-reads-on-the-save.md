An entry's save reads its collection's template on the save's own transaction, so a save in a collection served at an address set in the admin never waits for a second connection from the database pool, and only an entry with a slug takes its collection's lock. A collection's eligibility for a template address is judged from one read of its record, and `set-template-address` no longer reports a committed change as failed when the count of waiting entries cannot be read.
