The page-builder editor's small text and spacing now take the admin's sizes. Its
stylesheet reads the type scale (`--text-xs`, `--text-sm`, `--text-lg`) and the
spacing scale (`--space-*`) from the admin theme, but the admin's built
stylesheet emitted those only where its own Tailwind classes used them, so in a
production build the editor's labels fell back to the browser's 16px instead of
12px, and its gaps and padding to nothing. The theme now always emits both
scales.
