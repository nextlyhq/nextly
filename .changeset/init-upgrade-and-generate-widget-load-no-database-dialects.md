`nextly generate:widget`, `nextly init` and `nextly upgrade` start without loading drizzle's three database dialects, and `nextly setup-token --generate` without loading any database code. Commands that read a project no longer load the library that signs sign-in tokens, and load only the parts of semver they call. What every command prints is unchanged, except that the exit code 4 in each `--help` now reads "stopped by the start-up probe".
