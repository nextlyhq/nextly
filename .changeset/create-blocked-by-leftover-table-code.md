A create refused over leftover tables now ends a command with its own error code. When a collection, field group or Single create finds tables nothing registered owns where it would build, and they hold rows, are referenced from another table, or stand in the way of a junction table or under a view, the refusal reads as `CREATE_BLOCKED_BY_LEFTOVER_TABLE`, naming the tables and what to do, instead of an unexpected error. The code has its own page under the CLI error docs.
