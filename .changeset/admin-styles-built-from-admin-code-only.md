The admin's stylesheet is now generated from the admin's own code, the shared UI components and the first-party plugin screens, and nothing else in the package. Before, the build scanned every file in the package, prose included: a note or changelog quoting a class with an unfinished value such as `[var(...)]` produced invalid CSS that took down every admin page, and classes quoted in the changelog were shipped in the stylesheet. The stylesheet loses only those quoted classes; nothing the admin draws changes.
