A Single's schema save on SQLite now makes a column NOT NULL when Required is turned on, and nullable when it is turned off, including a Required field leaving translation. SQLite can't alter a column, so the save rebuilds the table in the same transaction as its other statements, with foreign keys off, keeping every row, key, index, translation and one-to-one's UNIQUE. A table with a trigger is refused unchanged.
