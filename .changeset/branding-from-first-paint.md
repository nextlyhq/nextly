The admin's logo and favicon no longer change after the page loads. With no logo configured, the rail, the sign-in card and the phone header all show the same boxed mark from the first paint. Branding set in `nextly.config` is read from the page itself when the admin route carries it (a `#nextly-admin-branding` JSON element), so a configured logo shows before any request answers and wins over branding set in General settings. The admin no longer replaces the page's favicon with its own default after load: with no favicon set the page keeps its own, a configured favicon is left as the page links it, and only a favicon set in General settings is applied.
