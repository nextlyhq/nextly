A public route answering a read the public is refused (an entry, a list or a Single it may not read) from the cache no longer fails to prerender under Cache Components with an error about reading the current time. `cachedFind` keeps the refusal and throws it again on every read of the entry; it now rebuilds that `NextlyError` without reading the clock, and takes its timestamp only when something, such as a log line, first reads it. The thrown error is otherwise the same: its class, code, status, messages and data are unchanged.
