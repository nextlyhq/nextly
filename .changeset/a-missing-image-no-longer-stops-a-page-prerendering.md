A public blocks page whose image names a media file that no longer exists no longer fails to prerender under Cache Components with an error about reading the current time. The route now reads its images through the same cache as the rest of the page, keeps a missing or refused image as no picture, and tags each read with the media collection and the file's id, so uploading, replacing or deleting the file refreshes the pages that show it.
