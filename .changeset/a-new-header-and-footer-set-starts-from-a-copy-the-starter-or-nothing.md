A new header & footer set starts in the builder. "+ New header & footer" in the Pages panel asks for a name and a start, then opens the new set on its own screen as a draft. The start is a copy of the site default, a new starter header and footer of its own, or empty. On a set's screen, each Header and Footer picker ends with "+ Create a header" (or footer), which makes a new published header from the plain starter design and chooses it for the set. A header another set uses too says "Also used by <set>", with "Make a separate copy", which points only this set at a copy. The set itself changes only with its own Save and Publish.
