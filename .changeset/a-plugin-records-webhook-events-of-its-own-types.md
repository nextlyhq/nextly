A plugin records events of the webhook types it declares with `ctx.webhooks.record` (experimental), in its own transaction with `tx` or on its own, and they are delivered to the endpoints subscribed to them or to `*`. A type the plugin does not declare is refused by name before anything is written. The event is stored in the existing columns, as kind `plugin` with the plugin's admin slug, so no migration runs; the delivery log shows it as the plugin's, never as a collection of the same name.
