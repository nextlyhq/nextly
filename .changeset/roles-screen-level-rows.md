Internal groundwork for the roles screen's per-collection access levels, with no change to what anyone may do. The admin gains the rows the roles screen will show, one per collection and Single, from the screen's list of entities and the permissions: the level a role's permissions give each row, what setting a level changes (only that row's standard actions; inherited permissions, the row's other actions and every other row are kept), and which levels a role's base roles leave on offer. Nothing uses them yet.
