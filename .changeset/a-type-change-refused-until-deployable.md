A Schema Builder field type change on a translated field is now refused, naming the field. Before, the save went ahead but left the field's column in the translations table, and every language's value in it, in the old type. A refused type change now also says why it can't be deployed yet: a value the database's cast would not rewrite into the new type's form (a list's one item, for example), or one it would not clear (a text that is no number). Changes the cast converts alike on every database, such as a whole number held as text becoming a number, go ahead as before.
