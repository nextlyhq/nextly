A collection whose entries are not all served under one pattern can name a text field holding an
entry's own public address: `publicAddressField` (experimental), beside `publicAddress`, which an
entry with an empty field still follows. `publicAddressOf` answers the entry's own address, so
canonical links, sitemap entries and redirects follow it. The value is judged as a template's
result is, and a save with an address no visitor could be served at is refused on the field; one
another page holds is refused as any clash, and changing it moves the entry's address.
