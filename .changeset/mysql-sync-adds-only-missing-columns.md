On MySQL, `nextly db:sync` and its watch no longer report "Failed to add column … Duplicate column name" for columns that are there. Every column of a new or changed code-first Single was tried again after its table had been made; so were the existing columns of a field group that gained a field, and those of a Schema Builder collection a plugin adds a field to at a start. Only a column the table misses is added now, and a column the database refuses is still reported. The tables themselves were right, and PostgreSQL and SQLite were not affected.
