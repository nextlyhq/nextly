Fix two page builder address-claim failures.

On MySQL, releasing a document's address while another save was recording a
wait for it could deadlock, and the release failed with "An unexpected error
occurred." A release now reads the document's claims without a lock to learn
which address locks to take, takes them, and only then reads the claims again
under them, so the two saves take turns instead.

A template saved for a collection with no address now finds the entries
holding addresses there on its own transaction, rather than through a second
pooled connection, which on a pool of one connection waited for the connection
the save already held and failed as "The database is busy."
