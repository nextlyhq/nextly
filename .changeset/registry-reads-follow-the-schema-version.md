The admin reads the collection, Single and field group registry once, and then not again until it changes. Registry rows and listings were kept for a second and read again after it, so a dashboard, list or edit screen read the same rows over and over; they are now kept until the database's schema version records a registry change, which every registry write (a Schema Builder save, a rename, a delete, `nextly migrate`, a plugin install) now does. Another server sees such a change within the two seconds it already takes to reload its schema.
