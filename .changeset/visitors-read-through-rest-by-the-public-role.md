Visitors can use the REST API for what the Public role grants. A request carrying no credential to a collection's entries or a Single is judged by the Public role, as a checked call with no user is: it may list, count and read published content, and create, update or delete an entry, where Public holds the permission and the target's rule, if it declares one, answers `true`. Without the permission it is still asked to sign in (401); a rule that refuses it answers 403. Versions, events, autosaves, bulk writes, duplicating and publishing still need a signed-in caller, as do media uploads and edits.
