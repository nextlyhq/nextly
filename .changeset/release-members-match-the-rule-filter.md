A release now admits a document where its author's publish or unpublish rule answers a filter that matches it, rather than refusing every document under a rule that answers a filter. Adding a document, switching its action and the readiness check before a run match the document against the rule's filter, as the run's own write does; a document the filter does not match is refused, and a document the author may not read is answered as one that is not there. An API key is judged by its own grants and rules as well as its maker's.
