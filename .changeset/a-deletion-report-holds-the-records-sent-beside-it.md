A plugin's deletion report made in its own transaction (`ctx.principals.reportDeleted(person, { tx })`) now holds the deleted-people lock from the moment it is called. An email sent alongside it in the same transaction waits for the report before recording its delivery, however long the report takes to begin. Before, a delivery record that arrived while the report was still checking its tables was written beside it on the same connection; on PostgreSQL, a failed insert there aborted the transaction under the report's next statement. The report's table check now runs on the transaction's own connection.
