The Releases page has a third view, Board, beside List and Calendar: the list's four tabs side by side as columns (Draft, Scheduled, Needs attention, Done), each with its first releases, its true count, and "+N more" to the rest of that tab in the List. The board is read-only: a release changes column by itself, so it is never dragged. The Releases page, a release's own page and the Translations page now name their place in the top bar's trail, as every other page does. In the Content sidebar, collections removed from code leave the everyday lists for a "Removed" fold at the end, which starts closed and counts them.
