Selecting a block in the page builder no longer asks the server for the site's collections and custom sources each time: they are kept for the signed-in author's session, so "Show when" and a list's settings appear at once. They are read again when another person signs in, after signing out, and when the schema changes. `@nextlyhq/plugin-sdk/admin` gains `schemaVersion()` and `onSchemaChange(listener)` (experimental), for a plugin that keeps an answer the schema decides.
