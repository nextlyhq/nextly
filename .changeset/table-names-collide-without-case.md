A table name that differs from another only in case is refused at startup, naming both spellings, since SQLite and case-insensitive MySQL treat the two as one table. An app table named like a collection's, a core or a plugin's table is refused naming that owner. An `afterDrizzle` hook that removes the column a declared foreign key stands on, or the table or column it references, is refused naming the key, rather than dropping the key from migrations in silence.
