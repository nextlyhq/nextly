A plugin can add foreign keys, checks and relations to another plugin's table. `extendTable` takes `foreignKeys`, `checks` and `relations` in the shape `defineTable` takes them, on a plugin's or the app's own table: the app on any plugin's table, and a plugin on the tables of a plugin it depends on. Each key and check ships in the contributor's migrations and is recorded as its element, so the table's owner never reads it as drift and uninstalling the contributor removes exactly what it added.

A plugin migration that rebuilds another plugin's SQLite table to add a key or check, and a DOWN that rebuilds one to take it off, are no longer refused by the schema guard.
