Storage can now hold a collection's private files, which no public address ever serves (experimental groundwork; collections opt in in a later release). A collection marked private is never written to the local disk: with no storage plugin that can keep files private, it is refused rather than served from `/uploads`, and `upload()`, public URLs, client uploads and signed downloads are refused for it. `@nextlyhq/storage-s3` stores private files under keys that name no file, never cached, with short upload and download links, and needs no `publicUrl` for them, on Cloudflare R2 too. A public upload on R2 with no `publicUrl` is now refused before the file is stored, rather than after.
