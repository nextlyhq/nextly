The page builder's Style tab has one reset per row. A value set at the edited breakpoint shows a reset icon at the end of its control's row, with a tooltip saying what it reveals ("Reset to unset", or the wider breakpoint whose value shows through). This replaces the "Reset to unset" line that made each set control two rows, and the separate clear buttons on lists and icon groups. A panel without a cascade offers the reset too, for any value stored at the edited address. The Content tab's Advanced section draws the panel's chevron in place of the browser's triangle.
