The page builder can now lock a shared style: a role holding the new "Lock shared styles" permission locks and unlocks it, and while it is locked nobody can change, rename or remove it. Unused shared styles are removed through a route that refuses a style still in use, and refuses every removal while some pages are still being counted; the same routes report how widely each style is used and where. A page save that adds a shared style the site does not define is now refused, while references a page already held still save.
