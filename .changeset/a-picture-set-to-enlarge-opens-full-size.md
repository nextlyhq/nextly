An Image set to **When clicked: Enlarge** now opens on the live page. The picture becomes a button, named "Enlarge: <alt text>" (or "Enlarge picture" when decorative), that opens the full-size file over the page with its caption, in the browser's own popover. **Close**, Escape or a click outside closes it; Close and Escape give the focus back to the picture. It adds no script to the page, so it works with JavaScript off, and the full-size file is fetched only when the picture is opened. The panel takes the site's colours, including its dark values, and fits the window from 320px wide up.
