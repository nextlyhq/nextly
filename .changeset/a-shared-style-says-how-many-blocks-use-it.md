A shared style says how many blocks use it, on how many pages and other places: "used on 12 blocks on 4 pages and 1 component" under the Style tab's chips, in Design's Shared styles and in Block looks. The open page is counted as it stands, unsaved changes included. The page builder's class usage index stores, for each page, how many of its blocks wear each class, and keeps it current on every save. A database migration adds that count, and after the upgrade the plugin counts every page again once; until it finishes, counts read "at least", and "Counting where it's used…" shows before the first answer.
