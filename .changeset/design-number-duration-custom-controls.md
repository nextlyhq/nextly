In the page builder's Design panel, the last of the "Other values" kinds get controls made for them. A number variable is edited with the same numeric field the block panel uses. A duration is a number with a menu of ms and s; changing the unit keeps the number, and a bare number takes the unit shown. A value that can't be split into a number and a unit, such as `var(...)`, stays editable as text. A custom value is a text field. Any variable's value that the site's stylesheet would not write, such as one that would load a file, is now refused where it is typed, with the same words the save uses, rather than only when the site's style is saved.
