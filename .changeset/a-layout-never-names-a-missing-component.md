A header and footer Layout can no longer point at a component that does not exist. Saving a Layout whose area names a missing component is refused with a message naming the area, and a Layout save that adds a component while it is being deleted is refused, so a save and a delete made at the same moment never leave a Layout naming a deleted component. A Layout stored earlier with such an area draws it empty and drops it at its next save of its areas, keeping the others; no migration is needed.
