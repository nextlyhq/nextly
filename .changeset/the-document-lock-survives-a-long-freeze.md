The editor keeps its document lock through a long freeze. When the browser stalls long enough for the lock to pass its renewal deadline (one long task on the main thread, or a hidden tab whose timers the browser slowed), the editor now renews the lock as it recovers instead of going read-only at once. It goes read-only only if a colleague holds the document. If the lease ran out and nobody took it, it claims the document again without displacing anyone, and someone else's save made in the meantime is still reported, so the form is held and a later save cannot overwrite it.
