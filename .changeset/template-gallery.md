The Schema Builder's new-entity dialog offers templates for a new collection, Single or field group. It shows a few quick ones and "Browse all templates": a gallery you can search and filter by category, where each template shows its source (built in, or the plugin that offers it) and the fields it adds. A picked template is checked field by field. Each field it cannot add is named with the rule it breaks and can be left out, and Create waits until none fails. Create adds the template's kept fields to the new entity, after any starting field.
