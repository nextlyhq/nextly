On a page with an Embed block, the Page Builder's canvas follows the device
and zoom controls again when the app runs in development. React's
development build describes a component's changed props by walking into
them, and the window the canvas handed to its blocks led that walk to the
embed's frame, which the browser does not let the admin read. The resulting
`SecurityError` stopped React partway through applying the update, so the
canvas stayed at the panel's width while the zoom read "Fit · 100%".
Production builds were not affected.
