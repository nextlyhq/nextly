A component placed on a page can bind its text, link and image settings to data, from the bind button on each setting in the placement's panel; inside a Collection list the list's entries are listed first. The placement stores the binding under `overrides.<setting id>`, and composing the component writes it onto the prop of the block the setting fills, so the canvas and published pages read it as any block's binding. A save refuses a placement binding key that names no setting. New `@experimental` exports: `settingBindingKey` and `boundSettingId`.
