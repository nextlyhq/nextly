"Used in N places" counts each page once. A font whose variables a page names twice, or a type size and its line height used on the same page, now counts that page as one place, on the Fonts screen and in the Variables tab. The variables usage route takes an optional `together` parameter: groups of the variables asked about, each counted as one, answered as numbers alone. Like every usage count, these include pages the author can't open. A host without it adds the variables' counts up, as before.
