Opening a plugin's admin page directly, from a bookmark, a refresh or a link, no longer shows "Page Not Found" while the admin loads. The page's address shows a loading state until the plugin pages are known, then the page itself, or a genuine not-found page if no plugin provides it. If the admin's metadata could not be loaded, it says so and offers Try again instead of waiting forever. Other addresses that match nothing still show not found at once.
