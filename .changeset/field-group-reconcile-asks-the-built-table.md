Reconcile no longer reports a repair, or refuses, on a healthy field group with a single reference or a checkbox default. It now asks the table built from the definition which index and default each field's column carries: a single reference is indexed whether or not it declares `index`, and a Builder save writes no column default for a checkbox. The default the field group's creator writes (`nextly db:sync`) is still accepted. A missing reference index, or a default neither writer gives, is still reported.
