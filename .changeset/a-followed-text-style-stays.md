A text style a Site text row follows can't be removed. The shared styles remove route, and a save of the site style that drops it, refuse while any row follows it, naming each row ("Eyebrow is used by Site text: Heading 1."). The code's rows count too. Pointing the row elsewhere in the same save lets the text style go. Text styles lock as shared styles do, and the lock holds them against removal.
