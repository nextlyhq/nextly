Dashboard cards keep their height from the first paint, so the rows under them no longer move when a card's data arrives:

- Each card's drawn height is kept on the device, per card and band of width, as a number alone, forgotten with the rest of what the admin keeps (on sign-out and by the site's off switch). A fresh tab draws each card's loading state at the height the card last stood.
- The setup card's loading state draws its checklist, a progress line and four steps, rather than list rows, so a first visit stands as tall as the checklist that replaces it for most projects.
