The Design panel's Block looks group now tells apart two block types' own looks that share an id when searching: each is found by its own name and the values it sets, so a search for one no longer lists the other or hides both.

A block type's own look is now held from editing whenever any other look or shared style in the site's library carries its id, not only another type's own look, since a write by id would reach both. The editing bar says why.

A worn look's row now counts the open page's blocks wearing it, unsaved ones included, beside the documents the site has counted, as a shared style's row does.
