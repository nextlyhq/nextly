`nextly migrate`, `migrate:down` and `migrate:create` now count a table a migration creates with `CREATE TABLE IF NOT EXISTS` as the migration's own when the database did not have it, so rows the same file writes into it and removes again ask no data-loss consent. A table the database already has, or whose presence cannot be read, stays live: a removal from it still needs consent naming it. `CREATE TEMPORARY TABLE IF NOT EXISTS` is read as before.
