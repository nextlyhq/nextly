The Email hub's Activity screen can find what was sent to one exact address. The address is sent only when a search is made, in the request's body. It is never put in the page's address, the browser's saved form entries or a cache key. The list then shows what went to that address, under the same filters, with the server's note on which older records a search can't reach. A search is never repeated by itself, since each one is recorded.
