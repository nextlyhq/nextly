`GET /me/capabilities` now names only the collections and Singles the signed-in caller may read, the same ones the collection and Single lists show that caller. Before, it named every collection and Single in the install, with `read: false` where the caller could not read one, so any signed-in user could learn every entity's name. A client that treated a missing entity as "nothing allowed" sees no change in what it may offer.
