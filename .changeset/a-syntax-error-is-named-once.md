A configuration that does not compile now names the place once, as your editor counts it, with the line itself: `CONFIG_SYNTAX_ERROR` and `CONFIG_IMPORT_NOT_FOUND` show `file:line:column` with a column counted in characters from 1 (it was esbuild's byte offset from 0, one short of the editor and further off on a line with text outside ASCII) and print the offending line beneath it, and the Next line no longer repeats the line number. The development server's reload message counts the column the same way.
