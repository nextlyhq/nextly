TypeScript sites can use seoStaticParams as a route's generateStaticParams without a type error. It
returned a readonly array, which the type check `next build` runs on a route refuses, so a site
that followed the guide could not build; it now returns the route's params as an array of its own,
and takes params a site keeps `as const`.
