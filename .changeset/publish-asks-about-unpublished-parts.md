Publishing a page whose components or Layout aren't published now asks first, in the editor and on the entry page: publish the page only, or publish the parts too, each as you, with any you can't publish named and left as they are. Making a Layout the site default asks the same about its header and footer components. Publishing a Layout from its own page now reports an unpublished header or footer component afterwards. A document action's before-action handler can cancel the action by throwing an `AbortError`. A storing action run while another is still readying is refused as busy rather than run twice, and a store keeps the refusal its writes gave a before-action handler.
