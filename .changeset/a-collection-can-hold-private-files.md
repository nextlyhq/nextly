A collection can declare that its entries are private files, with a `files` option (experimental): the accepted types, the largest size, and how a download is answered. It gains the fields each file needs (`filename`, `mimeType`, `size`, `sha256`, `storageKey`, `fileStatus`, `rejectReason`, `uploadedByKind`, `uploadedById`), which no caller can write through a checked path, and the storage key is never returned to one. The option is refused beside drafts, versions, localization, a public address or a read rule of `true`, and the Public role is granted nothing on such a collection at boot. Uploading and downloading the files come in a later release.
