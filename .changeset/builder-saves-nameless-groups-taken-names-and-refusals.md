A Schema Builder save of a field group that holds a group with no name no longer fails while it writes its migration. A field-group create under a name already taken is refused with the name, as `The field group "<name>" could not be created: its name is already taken.`, instead of the bare "Resource already exists.". On MySQL, a collection's Builder save refused because a column made required holds empty rows is refused with that reason, and its files are withdrawn; it was reported as a migration that failed part-way with its statements kept, and its files were left for `nextly migrate:resolve`, though none of them had run.
