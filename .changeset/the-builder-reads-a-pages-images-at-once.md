The page builder reads every image a page draws in one request, however many there are, and keeps what it read for the editing session. Before, it asked for each image on its own and read them all again a minute later. The media list route (`GET /media`) now also answers `?ids=a,b,…`, up to 100 ids, with those items in one read, under the same access as reading each one. `useMediaResolver` (experimental) groups every image asked for together into that one read, and an edit through the media library still makes the next ask read again.
