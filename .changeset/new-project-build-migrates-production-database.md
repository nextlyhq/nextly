A new project's `build` script now runs every `nextly` step with `--mode production`: `nextly migrate`, and each `nextly plugins install` step a registered plugin adds. A host that builds with `NODE_ENV` unset used to run those steps in development mode, so a deploy that takes `DATABASE_URL` from `.env.production` migrated the database named in `.env.development` while `next build` read the production one. A project made earlier keeps its script: add ` --mode production` to the end of each `nextly` step in `build`, as the production migrations guide describes.
