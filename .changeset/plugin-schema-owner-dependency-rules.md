A plugin that builds on another plugin's schema now has to depend on it. Adding a hidden column or an index to a collection, Single or field group another plugin declared needs that plugin in `dependsOn` (or `optionalDependsOn`), and so does an index over a column a third plugin contributed. Either one missing stops the app at startup, naming both plugins. The app is never asked: its schema runs after every plugin's.

To upgrade, add the owning plugin to the dependent plugin's `dependsOn`.
