Say where a rich-text image's identity actually lives.

The reference walker was documented as finding media inside rich text as an
identity token folded into the block's text. That representation was removed:
a decorator's identity is an ordinary property, compared under the path taken
to reach it and reported as an attribute change on its block. The comment
described a shape the code no longer produces, which is the kind of thing a
later reader trusts.
