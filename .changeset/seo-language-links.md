The SEO plugin links each page to its other languages. On a site with several languages, a page's head and its sitemap entry name every language the page is published in, itself included, with `x-default` at the default language's, each at that version's own canonical; a draft or missing translation is not linked. The sitemap lists each published language version of a page. Language codes are mapped to the ones search engines accept, and a language with none is left out. The `seo` group is kept per language on translated content types.
