A plugin's permission keeps its role grants when a start no longer declares it. The start marks
the permission orphaned as before, but setting the preset roles no longer takes an orphaned
permission away from them (or gives it to one that does not hold it), so the Admin role keeps its
grant and has it as before when the plugin returns. The log line written when a permission is
orphaned or declared again now names the roles that hold it.
