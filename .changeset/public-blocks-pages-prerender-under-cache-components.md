A public blocks page can now be prerendered under Cache Components. Each public read a page makes (a list, an entry by id, a Single, and the field shapes its bindings are checked against) is cached whole, so the judgement of which fields the public may see runs inside the cached read. A public route also caches its `siteStyles` provider's read, tagged with the Singles the provider names and named by the route and the provider, so two routes' providers never share an entry; an access-enforced route still reads it per request. Under Cache Components a prerender refuses a read outside the cache that takes the current time, and that judgement does when it checks the access rules are current.
