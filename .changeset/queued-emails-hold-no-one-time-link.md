An accounts email's one-time link or code is no longer stored in the jobs table. The queued job holds only a reference, and the link is rebuilt when the email is sent, so a copy of the database (a backup, a leaked credential) no longer holds a live reset or invitation link, before or after sending, and a failed send's error never names one. An email whose link was replaced, used or expired before it went is not sent. For plugin authors, `ctx.security.secrets` mints now return a `ref`, and `reveal({ ref })` derives the token or code again while it is live (experimental).
