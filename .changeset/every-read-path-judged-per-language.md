Every read path judges each language by that language's rules. A public read finds nothing in a language that is not published on these paths too: a Single read that selects only shared fields, and a related document, which is now withheld from a read in a language it is not published in rather than filled from a fallback language. A public Single route (`createPublicSingleRoute`) reads published content unless a draft grant applies. On a public read, the translation overview (`?translation-status=1`) reports published languages only, without pending changes or staleness, and the language filter (`_translated`) is judged by publication alone. A collection read clears a password a field's read hook puts back, as a Single read does.
