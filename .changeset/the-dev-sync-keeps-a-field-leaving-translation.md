A field a config edit makes shared on a collection, Single or field group that stays translated keeps its values under `next dev`: the default language's value moves onto the main table, and the other languages go to the archive, where `nextly i18n:restore` brings them back. Before, the main column was added empty and the translations were left in a column nothing reads.

A Required or Unique field leaving translation no longer prompts in the terminal: it is refused, naming the field and how many entries are in the way, when its default language's values cannot take the setting, and is otherwise carried by those values.
