A collection's stored hooks now show in its Builder settings, read-only, in a Hooks tab that appears when it has any: each hook with what it does to writes, when it runs, its settings and whether it is on, in the order the server runs them, and a hook this version does not provide marked as running nothing. A save from the Builder no longer sends stored hooks, so it leaves them as stored; before, a settings save dropped any hook the admin did not know and renumbered their run order. Stored hooks are still changed through the API.
