Page code and site code ask whether a page is drawn for a draft-mode request as
Nextly's own content routes do. A page drawn outside a request, by a test or a
script, now gets its published code instead of failing with "`draftMode` was
called outside a request scope". The plugin also no longer imports
`next/headers` itself, which plain Node can't load: a config that loads the
plugin's source, as the plugin's own upgrade test does, works with
`nextly migrate` again.
