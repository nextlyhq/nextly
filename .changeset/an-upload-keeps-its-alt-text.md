An upload keeps the alt text it is given. `nextly.media.upload({ file, altText })` stored every file without its alt text, so anything that needs one on a new image had nothing to read. The blog template's demo seed, for one, failed most of its posts, because a post refuses a featured image with no alt text. Alt text set on a file afterwards was never affected.
