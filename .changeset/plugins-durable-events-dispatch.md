Core now dispatches durable plugin events: a built-in `events:dispatch` job, run with the other jobs, fans each recorded event out into one delivery per durable subscriber registered at that moment, then runs each delivery until its handler succeeds, retrying failures with the jobs runner's backoff across restarts. Two dispatchers at once still make one delivery per event and subscriber. A delivery whose subscriber is no longer registered is held for it, never given to another, and looked at again every quarter of an hour; one that runs out of attempts (10) is kept as failed. A failure is kept with any credential in it taken out. Subscribing comes in a later release. Experimental.
