`nextly generate:types` leaves out of the component map a component a plugin contributes to an admin place when no file is behind its module, and warns with the component and the missing module; the map would otherwise import a file that is not there and stop the app compiling. `generate:types --check` and the admin's development check judge the same way. The page builder's admin entry no longer carries its stylesheet import in its type declarations, so its types resolve for every consumer, and the package no longer ships a test file in `dist/styles`. A number field's draggable label in the style inspector shows its resize cursor without overriding the admin's label cursor.
