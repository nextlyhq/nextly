`nextly plugins install` of a plugin that is already installed no longer records a second install or runs its `onInstall` again. It still applies any migration module the plugin's package added since, still adds any permission or role the package newly declares (with every preset role's grants and the release record, in one transaction, as a first install writes them), and exits 0. A deploy script that runs `plugins install --all` on every release now leaves the ledger as the first install wrote it. An install after an uninstall still runs `onInstall` and records the install.
