Publishing judges each language as it will land. A one-language publish of a collection entry whose pending change is behind newer shared values now goes through when the publish request itself sends the live value, as a Single's already did. Publishing every language no longer refuses two languages that make the same edit to a translated component's shared part. And a language with no pending change of its own is now validated over the shared values the publish leaves, so a change that would make another language's live content invalid is refused instead of putting it live.
