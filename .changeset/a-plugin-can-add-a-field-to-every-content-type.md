A plugin can add fields to every collection and Single a site defines without naming them. `contributes.extend` takes a scope as its target, `{ every: ["collection", "single"], except: [...] }`, which reaches the site's own types, including those made in the Schema Builder, and never a plugin's own types, Nextly's system types or field groups. A type the scope reaches that already has a field of that name is left as it is and named in a warning at startup. `typesReachedBy` and the `ContentTypeScope` type (`@experimental`) give the same answer to anything else that needs it.
