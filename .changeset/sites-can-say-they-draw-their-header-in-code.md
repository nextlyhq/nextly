Sites that draw their header and footer in their own code can say so with the page builder's new `siteHeaderFooter: "code"` option (default `"page-builder"`). An unknown value stops the server at start with an error naming the option. When the editor's canvas shows the site's own header or footer around the page and a header & footer set draws one too, the editor says once a session, above the canvas, that visitors may see two, with a link to the docs.
