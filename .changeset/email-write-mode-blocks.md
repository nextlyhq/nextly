The email workbench edits an email written in blocks (`@experimental`). A written email's body is a list of blocks in place of the code editor: headings, text with bold and italic, buttons, images with their alt text, dividers, spacers, and lists that repeat their own blocks for each item of a list variable. Each block can be dragged by its handle, moved with Move up and Move down, duplicated, and removed with Undo. The preview renders the blocks as a send does.

The New email dialog asks how a blank email is made, Write it or Code it, and a new written email starts with a heading and an empty text block. Coded emails are unchanged.
