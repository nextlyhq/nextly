Design > Fonts can now add a font from the Google Fonts catalogue: the server downloads its files into the site's media, so published pages load fonts only from the site and visitors never contact Google. The inspector's Font control picks only the site's fonts, and uploading a font file still works.

While an author browses the catalogue, the editor's browser loads previews from the catalogue's file host (`cdn.jsdelivr.net` by default, or the `files` host given in `pageBuilder({ fonts: { catalogue } })`); the catalogue's list and every added file are fetched by the server. `pageBuilder({ fonts: { catalogue: false } })` turns the catalogue off.
