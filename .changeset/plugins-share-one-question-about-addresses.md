A plugin that keeps a record of who holds each public address can take part in keeping every address to one page, through `ctx.publicAddresses`. Nextly asks every participant inside each save whether another page holds an address the saved document now holds, and refuses the save with `DUPLICATE`, naming both pages, if one does. A plugin that moves addresses itself asks the same way with `move`, and `held` and `fingerprint` let a participant catch its record up at start. Nextly keeps no record of its own, and a site with no participant does no address work. Experimental.
