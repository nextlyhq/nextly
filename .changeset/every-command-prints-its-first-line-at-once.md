Every `nextly` command prints its first line as soon as it starts, before its own code loads, which takes seconds. A command that uses a database names it there (`Database: SQLite ./data.db (development; DATABASE_URL from .env)`); one that does not prints a short line saying what it is starting, such as `Reading the configuration...`. Both go to standard error, so `--json` output stays one document, and `--quiet` keeps them back. How long a command takes in all is unchanged.
