A form that redirects to a picked page sends a public visitor to the page's published
default again when the page's translation in the visitor's language is still a draft.
Since a public read in a language finds nothing for a document not published in it, the
redirect read found no page and the visitor was sent nowhere.

Plugins can now ask `ctx.services.collections.findEntryById` for whole-document fallback
with `wholeDocumentFallback: true`, the plugin spelling of `?fallback=document`: the entry
answers in the first language of its fallback chain that it is published in, and says
which in `_locale`. Every other method refuses the option.
