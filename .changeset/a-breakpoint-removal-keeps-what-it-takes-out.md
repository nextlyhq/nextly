A confirmed breakpoint removal now keeps what it takes out of the site, so it can be undone: every stored value it strips (a page's live row or working draft, a component, a pattern, a Layout, an entry) has a row in the page builder's new `breakpoint_removal_fragments` table holding the styles and hides it lost, written before the strip itself, and the shared styles have one for what the set's write took out of them. A strip whose row cannot be written is not made. Rows are deleted by the removal job 30 days after they were kept. Existing installs apply the new table with `nextly migrate` before deploying (the page builder's schema version is now 6).
