New projects now ship the route that serves local uploads, `src/app/uploads/[...path]/route.ts`, and `create-nextly-app` writes it into an existing app it adds Nextly to, unless the app already answers `/uploads`. A production server then serves an upload the moment it finishes, with nothing to add by hand. An app created before this release adds the file itself, as [Media & Storage](https://nextlyhq.com/docs/guides/media-storage#how-local-uploads-are-served) shows.
