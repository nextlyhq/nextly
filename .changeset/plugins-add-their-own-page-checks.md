A plugin can add its own checks to the page builder's Page checks list. `@nextlyhq/plugin-sdk/blocks` gains the experimental `PageCheckProvider` contract, which a plugin registers from its own `init` through the page builder's `pageChecks` service, before or after the page builder starts. Each provider runs on the server, as the person editing, and its findings are listed in the group it names, with the same click-to-fix as the built-in checks, including opening Page settings at a tab. A provider that throws or takes too long is listed as not run. The list asks the providers again after each save and each time Page settings closes.
