The admin no longer sends autosave requests for a collection or Single with autosave turned off. The entry and Single editors, and the Page Builder canvas inside them, used to record recovery points there anyway; the server refused each one, so every editing session filled with refused requests. Where autosave is off they now record nothing, look for no recovery point and show no autosave status. Nothing changes where autosave is on.
