`nextly migrate:baseline` counts as history only the app migrations whose latest outcome is applied. A migration rolled back, file present or not, and a plugin's module no longer stop a project from adopting migrations; one applied and then edited (the edit accepted) or removed on purpose still does. The refusal now lists every migration it counted, each with the step that clears it. A baseline also refuses while an app migration has an unresolved attempt on any database, naming it and the `nextly migrate:resolve` step, including a failed attempt a transaction undid.
