A block clicked in the page builder with a container selected now goes inside it: select a Section and click Heading, and the Heading lands at the end of the Section. Layout blocks (Box, Columns, Card) still go after the selected container, so Box then Box gives two Boxes, and a Section added while a block inside a section is selected goes after that section. The Add panel says where the next block will land ("Adding inside Hero, at the end", "Adding after Heading, inside Hero"), and a screen reader hears what was added and where. Search and the Components panel place blocks the same way.
