A plugin can add to another plugin's admin place when that plugin is installed, and still start without it. A contribution to a place owned by a plugin named in the contributor's `optionalDependsOn` is left out while that plugin is absent or disabled, instead of stopping the app with `admin-place-unknown`. A place the running owner does not declare, or one of a plugin the contributor does not name, is still refused.
