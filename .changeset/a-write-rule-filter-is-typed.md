A collection's `update`, `delete`, `publish` and `unpublish` rules may return a filter in their declared type, as its `read` rule may: `defineCollection` types the filter by the collection's own fields, so a misspelt field or operator, or a value of the wrong kind, fails to compile. `CollectionAccessControl`'s `update`, `delete`, `publish` and `unpublish` now accept a rule that answers a filter. Code that stores one of those rules as a general rule should type it `AccessControlFunction | boolean`, which every operation still accepts.
