A translated field added to a collection, Single or field group that is already translated is recorded in its migration: `nextly migrate:create` writes a file that adds the field's column to the translations table, and `nextly migrate:down` removes it. Before, it wrote nothing, and the column appeared only when `nextly migrate` later reconciled the translations table. The file is a new kind of localization migration, so it needs this version of Nextly or a newer one to run.
