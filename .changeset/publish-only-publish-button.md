A user who may read and publish an entry, but not change it, now publishes it from the read-only page: Publish on a draft, and Publish changes on a published entry holding an editor's draft. Publish and Unpublish send the status alone, which their own permissions judge, so they go through where a save is refused; Unpublish on the read-only page now works too. The same holds for a Single with a lifecycle. `GET /me/capabilities` answers `publishEveryLanguage` with publish alone on a collection with a Draft/Published lifecycle, so the admin offers Publish all languages to such a user; a Single, and a collection without a lifecycle, still ask update too.
