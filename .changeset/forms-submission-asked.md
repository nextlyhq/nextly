Each new form submission keeps what it was asked: each field's label, type and option labels, and which fields its conditions hid, so it reads as it was answered after the form changes. An answer staff edit keeps the label it was edited to. A submission stored before this reads with the form as it is now.

Existing installations receive the new `asked` column on the submissions collection through their own migrations: run `nextly migrate:create` and then `nextly migrate` (or `nextly db:sync` in development).
