A release holding a document of a collection or Single removed from code now counts it as a hard problem, `ENTITY_REMOVED_FROM_CODE`, naming the entity. The release's readiness shows it, and scheduling, Publish now and adding the document to a scheduled release refuse while it remains. The first job pass after the deploy that removed the entity stops each scheduled release holding one, before its time, and tells its owner. Take the document out of the release, or declare the entity again, to schedule it again.
