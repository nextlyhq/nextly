A document view can declare its own create dialog. With the new, experimental `createDialog` on a document view, a collection whose entries open in that view opens the plugin's dialog from its list's "+ New" instead of the create form. The dialog receives the collection and `close(createdId?)` (typed as `DocumentCreateDialogProps` in `@nextlyhq/plugin-sdk/admin`); closing it with the new entry's id opens that entry where its collection opens entries. Collections that open as the form, and views without a dialog, keep the create form.
