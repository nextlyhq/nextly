Removing a breakpoint no longer stops a text style the site's code supplies with a fluid size from following the site's fluid range. Where the site stores a range other than the code's, the override the removal stores of that style now holds the size the site's range gives and keeps its two sizes, so a later range change remakes it, as it does any text style made with "Fluid…", and the lock guard accepts that write for a locked one. Undoing the removal takes that override out again so the code's style applies, including after the range has changed since.
