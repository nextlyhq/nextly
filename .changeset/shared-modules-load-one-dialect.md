Some `nextly` commands start faster, because they load only their own database's code rather than PostgreSQL's, MySQL's and SQLite's. `generate:types` loads none of the three. `events report`, `webhooks:prune`, `permissions:cleanup`, `workflow:stranded`, `media orphans` and `users:clear-plaintext-passwords` load one, as do the dry runs of `media reindex-usage` and `i18n:restore`. `migrate` and its subcommands, `db:sync` and `repair-columns` gain nothing: they still load all three. An app's start gains nothing either. No table, index or migration changes.
