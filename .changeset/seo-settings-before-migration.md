A site that upgrades the SEO plugin keeps its SEO before it runs `nextly migrate`. When the database has no column yet for a setting a newer release added to the SEO settings, that setting is read as unset (its default), the other settings are read as saved, and the log says once which setting waits for the migration. Before, every page lost its SEO answer, and the sitemap and robots.txt their settings, until the migration ran. Saving the settings screen in that state is refused with the message to run `nextly migrate`.
