Plugins get `ctx.security.digests` (`@experimental`): `digest(purpose, value)` returns a keyed one-way digest (HMAC-SHA256) of a value a plugin compares without keeping it, such as an email or IP address. Each plugin has its own random key, made once and kept in `nextly_meta` sealed under `NEXTLY_SECRET`. A secret rotation seals the same key again at the next start, so digests stored before the rotation keep matching once the previous secret is removed. The `KeyedDigests` type is exported from `@nextlyhq/plugin-sdk`.
