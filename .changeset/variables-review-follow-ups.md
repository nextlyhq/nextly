Follow-ups to variables with light and dark:

- `prefersDark={false}` on the editor shell keeps the Variables preview light again. Omit it to follow the device.
- Each half of a type size's dark value (size, line height) can return to the light value on its own.
- An import refuses two files when one name says both light and dark, and applies and counts only the variables it changes. An import that changes nothing saves nothing.
- The Figma export leaves out a variable whose name the engine refuses, and says so, as the standard export does.
- The canvas's colour scheme follows the nearest light or dark marker.
