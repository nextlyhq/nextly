A super-admin's full-access API key now has its authority answered once per request: every check the request makes gives the answer its first check gave, so a request that crosses the moment the authority lapses is no longer refused partway through, for example at a publish after its route admitted it, at a plugin route's write after the route's permission gate, or at each entry of a bulk publish. A request that starts after that moment is refused at its first check, as before.
