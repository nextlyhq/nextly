A plugin's write made as a user inside `ctx.services.collections.withTransaction` reads that user's roles on the transaction. They were read on the pool, outside it: a role the transaction had taken away was still on the caller a field rule reads as `req.user`, so a rule checking `req.user.roles` could allow a write the transaction's own roles refuse, and on PostgreSQL and MySQL each lookup ran on another connection while the transaction held its own.
