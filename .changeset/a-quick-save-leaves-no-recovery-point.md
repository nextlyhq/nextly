A quick save no longer leaves a stray recovery point behind it. An edit schedules an autosave recovery point a moment later, and a save that finished inside that moment left the timer running, so it then recorded the just-saved values as unsaved work. The pending recording is now dropped when a save leaves the form clean, and a recording is only made while there is still unsaved work.
