A Single's table no longer carries a field's default as a column default: the default is applied when the Single's document is written, as a collection's is, and as the schema a migration is written from describes the column. A required field added to a Single that already holds its row fills that row and leaves its column with no default. A Single's columns that already carry such a default keep it until it is converted.
