Under Cache Components, Nextly's cached reads can now go through a `"use cache"` function of the app's own, registered with the new `registerCachedRead` and `runRegisteredRead` from `nextly/runtime`, so a page read right after a write shows the new version with Nextly's cache handlers installed. The blog template ships `src/nextly/cached-read.ts` as a stub that registers nothing while Cache Components is off, and its Cache Components version beside it. With Cache Components on and no function registered, Nextly warns once at the first cached read. Nothing changes with Cache Components off.
