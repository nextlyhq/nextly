A write made inside a transaction no longer runs retention passes from inside it. A pass runs its own statements on the connection pool, outside the transaction and blind to its writes, so the write path now offers none while a transaction is open. Passes run on the next write made outside a transaction, or on the scheduled drain. The cache tag expiry ledger's prune, which runs on every install, was the first pass to show this.
