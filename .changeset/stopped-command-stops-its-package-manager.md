Stopping `nextly upgrade` or `nextly add` stops the package manager it started. Ctrl+C, a request to end (SIGTERM) and a closed terminal (SIGHUP) are passed on in every phase, the package manager is waited for, and the command exits 130; one that does not stop within 10 seconds, or at a second Ctrl+C, is ended. An upgrade stopped while it installs puts `package.json` and the lockfile back. Before, an upgrade stopped while it asked the registry or put packages back left its package manager running.
