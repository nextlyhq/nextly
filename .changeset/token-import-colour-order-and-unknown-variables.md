Importing a design token file no longer has its save refused over one bad part. A colour order the site can't store (an id listed twice or empty, or more than 1,000) is skipped and named in the preview, judged by the same rule the stored site style is held to, now one implementation in the engine (`isColourOrder`), and the rest of the file imports. A text style naming a variable that neither the file nor the site has is left out and named, so the other text styles and Site text still import.
