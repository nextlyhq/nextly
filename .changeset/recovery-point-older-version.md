The offer to restore unsaved changes knows when the document has been written since the recovery point began. The server keeps where the document stood when each recovery point was first recorded, and says whether it has moved since and whose the newer write was. An editor offers such a point with a warning that restoring it replaces changes made since. This covers pages, components, Layouts and Singles. A save, and publishing every language, also waits up to 5 seconds for that document's recovery point already on its way, so one sent just before can no longer land after it and be offered as current.
