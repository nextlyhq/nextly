`@nextlyhq/admin-css` now exports `isolateAdminStylesheet(css, { prefix })` and `ADMIN_NAME_PREFIX`. The function is the admin stylesheet's whole isolation sequence, in order: every selector scoped under `.nextly-admin`, keyframe names and registered `@property` names prefixed, and then a check that throws if any rule escaped the scope. The admin's own build now calls it, and so can a tool that compiles the admin's source stylesheet itself. The admin's published stylesheet is unchanged, byte for byte.
