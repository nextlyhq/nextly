**Storage:** the versions table gains two nullable columns, `changed_locales` and `shared_changed`. Each new version records the languages it changed and whether it changed the shared part: on a publish, the parts it put live; on a held save, the parts it wrote. `nextly migrate` and both boot paths add the columns to an existing database; versions recorded before them read as unknown.
