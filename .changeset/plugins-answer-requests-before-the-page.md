Plugins can answer a request before its page is served, or add headers to every page, prerendered ones included. A site wires its Proxy once, `export const proxy = createNextlyProxy(nextlyConfig)` from `nextly/runtime` in `proxy.ts`, and each plugin contributes handlers under `contributes.proxy`; a handler may answer with a response such as a redirect, set headers on what is served, or pass headers on to the page's render. A handler that throws is logged and passed over, so the site keeps serving.
