An undo of a breakpoint removal now leaves the removal's claims on its breakpoints in place until its own set has been stored, so an undo refused by another save no longer lets pages the removal left (a pending draft) bring those breakpoints back early. An undo whose write cannot be confirmed stays preparing until its recorded set is seen stored, and is never walked unverified. What an undo could not put back counts each value once, however often the removal stripped it, and the values of a code-supplied shared style removed from the code since are reported as gone with it rather than as put back.
