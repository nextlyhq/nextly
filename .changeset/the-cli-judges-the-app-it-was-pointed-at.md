`nextly`'s start check judges the Next.js, React and React DOM of the app a command was pointed at. A plugin's `onInstall` or `onUninstall` run with `nextly --cwd apps/site plugins …` used to read the directory the CLI was started in. From a monorepo root that installs none of them, an unsupported app went unjudged. `registerServices()` takes an optional `appRoot` (default: the process's directory), and `loadConfig()` returns the `projectRoot` it resolved.
