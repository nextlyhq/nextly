`nextly db:sync` keeps a field's values when the field stops being translated. Before, setting `localized: false` on a field of a translated collection, Single or field group left every value in the translations table and gave the field an empty shared column, so every read of it came back empty. The sync now moves the values the way `next dev` does: the other languages go to the localization archive, the default language's value becomes the shared value, and then the translated column is removed. A Required or Unique field gets its setting once its values are copied. When they can't take it, the sync refuses before anything changes, naming the field. `nextly db:sync --watch` does the same on each re-sync.
