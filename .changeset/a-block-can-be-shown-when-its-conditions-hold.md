A block gets a "Show when" group in its Content tab, under "Visible on": one group of conditions, each a field, an operator and a value, edited as a list's filters are. Only fields visitors can see are offered. A block inside a collection list checks the list's item, and every other block the entry the page shows. A condition the page can't check says so, since visitors then never see the block, and groups set through the API are shown as they read, with a way to keep the first. The page actions API gains `set-conditions`, which sets or removes a block's conditions with the same checks as the editor's save.
