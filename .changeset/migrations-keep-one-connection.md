`nextly migrate` and `nextly migrate:down` now apply each migration file inside one transaction on one database connection. Before, the `BEGIN`, the statements and the `COMMIT` or `ROLLBACK` could each run on a different pooled connection: a migration that failed halfway could leave its first statements applied, and return a connection to the pool still inside an open transaction (#1964).
