A plugin can take part in deleting a collection: `ctx.hooks.onCollectionDelete`
(experimental) says what the delete takes with it, which the admin's delete
dialog now lists under the plugin's name before the confirm, and removes it
inside the delete's own transaction, so a plugin's throw refuses the delete
and nothing it holds is left naming a collection that no longer exists. The
page builder uses it: deleting a collection deletes its template with it.
