`user_roles` gains an index on `role_id`, `user_roles_role_id_idx`, on PostgreSQL, MySQL and SQLite. Finding the accounts that hold a role, which the check that keeps the last active super-admin from being removed makes inside every write it judges, no longer reads the whole table.

An existing database gets the index from `nextly migrate`, or from the next development start; nothing else about `user_roles` changes, and no migration file is written for it.
