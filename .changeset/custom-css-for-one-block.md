A person who may change the site's settings can now give one block its own CSS, in the last section of the block's Advanced tab, Custom CSS. The box takes CSS written with `selector` for the block; leaving it or pressing Apply checks the CSS with the same checker the server uses, and either applies it as one undo step or lists each refused line with its reason. The section stays folded until opened, with a dot while the block has CSS. Everyone else sees that a block has custom CSS but never the CSS: a "{ }" mark on its Layers row and a line at the top of its Style tab. Find a setting finds the section by "Custom CSS", "CSS" or "code", and Only changed counts it.
