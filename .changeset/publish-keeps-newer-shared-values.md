Publishing a language's pending change no longer puts back a shared value that someone else published after the change began. Each pending change records the version it began from. When a shared field's live value has moved on since, the publish is refused with a 409 that names the field (fields the caller can't read are counted, not named), and nothing changes. Taking the live values for the pending change brings it up to date, and the next publish goes through. When every language of a Single is published together, the later save's value is kept for a shared field two languages both changed.
