With Cache Components on, a page built in code that answers not found while `next build` renders
it is left out of the sitemap and `llms.txt`, as it already was with them off: Next.js keeps that
answer only in the record beside the page, which the plugin now reads. The guide's
`global-not-found` sample reads the request inside `<Suspense>`, so a site with Cache Components
on builds with it.
