The admin now draws what plugins add to four of its places (experimental).

- Settings, a user's detail page, the entry form (in both the collection entry and the Single editor) and the login page draw the blocks sent to them, in the order sent, each behind its own error boundary, and settings and a user's detail page draw contributed tabs after the page's own content.
- A page with nothing contributed is unchanged.
- The login page's contributions are kept after signing in, beside the signed-in places'.
- A plugin draws a place it declared on its own page with `TargetSlot` and `PlaceTabs` from `@nextlyhq/plugin-sdk/admin`.
