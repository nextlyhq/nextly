A Single's read now honours `select`, with the meaning it has on a collection read: the fields named `true` are answered, with the id and the system timestamps, and a selection naming none answers the whole document. Where no read hook or field read rule needs the other fields, the read takes only the selected fields' columns, so a field whose column `nextly migrate` has not created yet fails only a read that selects it.
