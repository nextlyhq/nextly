A change to what a role grants now expires the cached content pages until the expiry lands,
rather than trying twice and logging an error. The expiry is queued as a job before it is tried
and withdrawn once it lands, so if the process stops first, the next jobs run (`/api/jobs/run`)
expires the pages. A process still running tries again, waiting longer each time, up to a
minute between tries.
