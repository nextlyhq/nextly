A foreign key may only target a table an earlier migration stream creates, a plugin keying to another plugin's table must declare the dependency, a plugin module's keys are judged against its own modules' order at generation and before a run, and a declared check or expression index is refused on a server that cannot hold it, naming its version. A key whose target the app's stream or a later plugin creates was left to the database to refuse at a fresh install; now the declaration is refused, naming the stream. On MySQL before 8.0.16 a declared CHECK parsed and held nothing, and before 8.0.13 an expression index failed to build; both are now refused at the compile the push and the migration share, and a shipped plugin module's snapshot is judged again before any module runs.
