In the admin, "Take the live values" on a publish refused over out-of-date shared fields now saves the editor's form as it is when the action is taken, so edits made after the refusal are no longer lost when the editor reloads. The editor then shows the live values of the fields taken, keeping its other edits, so publishing again no longer sends the old value and puts it back live. The refusal toast is one per document and language, and closes when the editor leaves them.
