An image binding's fallback can now be a media library image as well as an image address. It is accepted when the page is saved, draws as a picked image does (the record's address, alternative text and size), is kept in the media prop when the image is unbound in place of a field visitors can't read, and travels with a page's export and import: the export carries its media file, and the import maps its id to the file on the new site or reports it missing, as it does for the image's own media.
