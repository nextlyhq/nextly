A plugin can read a collection's record inside a transaction it holds:
`ctx.services.collections.getCollectionInTransaction` (experimental) answers
what `getCollection` answers, on the transaction's own connection, so on a pool
of one connection it answers where `getCollection` would wait for the
connection the transaction holds. The page builder reads whether a collection
has a Draft/Published lifecycle with it inside an entry's save and a
template's publish, so a save in a collection served at a template address no
longer waits for a second pooled connection.
