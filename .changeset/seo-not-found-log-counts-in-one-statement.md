`ctx.db.update` takes `increment(n)` for a numeric column, exported from `@nextlyhq/plugin-sdk/db` (experimental): the update adds to the stored value in its own statement, `column = column + n`, on every dialect, so updates made at once each count. The SEO plugin's not-found log moves from a collection to the plugin's own table (`seo__not_found`) and counts a request for an address already logged in one statement, and a first request in at most three, where each was a whole entry save of about 80 statements before. Rows an earlier version logged are moved to the table at start; the old collection stays declared and is left empty.
