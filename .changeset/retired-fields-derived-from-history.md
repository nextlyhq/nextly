A component field removed by a publish now stays retired even when the write that records it fails. The Page Builder derives a component's retired field and slot ids again from its published history (every id a published version exposed, minus the ids the newest published version exposes) and records any its retired list lacks. It does this right after a failed record, and whenever the component editor asks for the ids it must not reuse, so a new field is never given a removed field's id and old placement values never come back on it. A field only a draft ever held is not retired.
