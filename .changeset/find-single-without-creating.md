`findSingle` takes a new `createIfMissing` option. It defaults to `true`, which is how every read already behaves: reading a single that has never been saved creates its default document. Pass `false` to read without writing. A single with no stored document then answers `null` (the return type includes `null` only for such calls), and nothing is created: no row, no version and no event. Existing calls are unchanged.
