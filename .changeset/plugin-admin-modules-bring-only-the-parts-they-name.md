A site whose plugins have admin pages loads less before the admin's first screen draws: a plugin's admin module, which the app's component map loads up front, now brings only the admin parts it uses, not the whole plugin kit. In a production build of an app whose plugin draws one plugin-page part, the admin's first load falls from 741 KB to 570 KB (gzipped). Plugins change nothing: they import from `@nextlyhq/plugin-sdk/admin` as before, which now takes each part from its own internal area (`@nextlyhq/admin/kit/<area>`).
