The page builder canvas judges a placed component's own conditioned blocks as it judges the page's, so one the page can't check is badged red. Two conditioned blocks in one component get a badge each, and a badge stays clear of the block toolbar and on screen at either edge. Only the components a page places are prepared for the canvas, and conditions stored as an empty value can be removed from the inspector.
