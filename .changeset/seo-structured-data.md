Every page served by a route helper now carries structured data when the SEO plugin is installed. The plugin describes the site, the page, a breadcrumb trail and the page's subject as one linked schema.org graph, built from the same answer as the page's head, and the route hands it to the page's `render` as `context.structuredData`, JSON-LD text that no value can break out of. A content type chooses its pages' type among those Google still shows (Article, Blog post, Web page, Collection page, Profile page, Software app, Product, Event, Video, Review, Local business), a page can choose another, and a type missing a detail it needs is left out and listed as a problem naming it.
