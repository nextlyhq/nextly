A List picks Bullets, Numbers, Checks or None. Checks draws a tick in the text's colour;
None draws no marker and stays a list to a screen reader. On the canvas, each item is
typed in place: Enter adds the next item with the words after the caret, and Backspace
in an empty item removes it, each one step to undo. The panel labels items Item 1,
Item 2. An array of words declared `inline` is edited item by item, each item's
element marked with `itemPropName(prop, index)` from `@nextlyhq/blocks-engine`.
