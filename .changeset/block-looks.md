Blocks can declare looks: named variants such as a button's Secondary, Outline
and Text, an image's Rounded and Circle, and a section's Hero. A look is a
`variations` entry with `styles`, and the site receives it as a shared style
bound to that block type, supplied by code and editable by the site. Looks are
written before every other shared style, so a shared style and the block's own
values still win over them. The core blocks ship these looks, built from the
site's tokens. The Add panel lists each block once, and looks stay out of the
shared styles list and picker until their tiles arrive in the inspector.
