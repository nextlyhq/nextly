The development-only cold-boot notice no longer tells a project its instrumentation file is missing. A first request that reaches Nextly while a server-start boot is still under way now hears that the request arrived before Nextly finished starting, and one that arrives before any start is observable hears that no start was observed — with the add-the-file advice kept as conditional guidance rather than a diagnosis. The `NEXTLY_DISABLE_INSTRUMENTATION_WARNING=1` suppression and the development-only gate are unchanged.
