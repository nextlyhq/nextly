On MySQL, `db:sync` and the dev reload keep a code-first field group's text column at the width they narrow it to. A text field that states no width is `varchar(255)` in a field group defined in code, as the sync plans it, but the table handed to the push described it as TEXT, so every sync narrowed the column and the push widened it straight back.
