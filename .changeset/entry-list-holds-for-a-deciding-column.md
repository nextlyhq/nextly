An entry list no longer moves its cells when a plugin's column arrives after the rows. A column provider whose columns rest on a read of its own can now say so with `ctx.deciding(until)` (experimental), and the entry list keeps its outline a moment longer (250 ms at most, timed from the rows' arrival) while one is still deciding, then draws the rows with the column. The Page Builder's Design column says so while it reads whether the collection has a template, and its cells draw from that answer until their own read lands, so the column no longer changes width either.
