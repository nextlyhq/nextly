A blog scaffolded with the code-first approach now gets its first migration written from its own config. Once the dependencies are installed, the CLI runs `nextly migrate:create initial` for the database you chose, so the build's `nextly migrate` creates every table the blog reads, the form-builder plugin's included. Before, the scaffold copied the visual blog's hand-written SQL to a folder the code-first config never read, so the build migrated nothing. With `--skip-install`, the next steps name the command to run after installing. A visual blog still gets the template's migration.
