A registry row or listing that is not kept yet is now read once for every request that asks for it while the read runs, instead of once per request. The first admin screen after a server starts asks for the same collections', Singles' and field groups' rows from several requests at once, and read each of them as many times over (16 to 20 row reads on its first sign-in); they now share one read each. A read begun before a registry change is never shared with a request that arrives after it, and a read that fails fails every request that waited on it and is not kept.
