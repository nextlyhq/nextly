The Schema Builder's field save refuses a new or renamed field named `status` or `first_published_at` while the collection's or Single's Draft/Published lifecycle is on, naming the field, where it used to be refused late by the schema file, fail as a duplicate column, or take over the lifecycle's own column. It also refuses a field whose column would be longer than 63 characters, which MySQL rejects and PostgreSQL cuts short. A field already saved under such a name keeps saving its other edits.

`nextly/config` publishes `fieldNameProblem` (experimental): the rule the Builder's field save refuses a name by, so the admin can check a name by the same rule as it is typed.
