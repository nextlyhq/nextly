A blog category or tag whose slug is `__none__` renders its posts. The blog's archive routes give the build that slug as a placeholder when the site has no archives yet, and its page answered the not-found page on every request too, so a real archive with that slug could never be seen. The placeholder now stops before the database only while `next build` runs.
