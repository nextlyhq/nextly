A plugin can find the host content that uses its field type inside a
transaction it holds: `ctx.services.ownCollections.listHostTypesInTransaction`
(experimental) answers each collection and Single holding a field of a type
the plugin registered, at any depth, as `services.collections.listCollections`
and `services.singles.list` list them. It reads on the transaction's
connection, so on a pool of one connection it answers where those listings
would wait for the connection the transaction holds.
