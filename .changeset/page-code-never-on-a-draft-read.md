A page's own code is no longer drawn on a draft read of the page. A
signed-in preview route (`createContentPage` with a `pages.draft` gate) can
serve a working draft, or a page never published, without Next's draft-mode
cookie, so the draft-mode check alone let unpublished page code run there.
What `pageBuilderContent()` draws around a page is now told the entry it was
read as, and draws page code for a published read only.
