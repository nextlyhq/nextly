A blocks field inside a named group (`hero.body`) can be saved again when the page
already stores a `"contentOnly"` value or a placement break it keeps. Its stored value
was refused as "not a top-level field", which failed the save. A plugin field
validator's `write.readStored` now reads a field inside named groups by its path.
