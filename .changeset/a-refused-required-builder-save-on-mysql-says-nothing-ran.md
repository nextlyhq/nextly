A Builder save on MySQL that makes a field required while rows hold no value in it is again refused with its reason alone: nothing of it ran. MySQL writes that change as a statement built from the live column, which the save could not read a table from, so it reported the refusal as a migration that failed part-way, told you to settle it with `nextly migrate:resolve`, and kept the save's files. It now reads that statement as the column change it makes.
