A field that makes no column of its own (a field group's field) is no longer refused in the Schema Builder for a name longer than a column may be. The Builder now asks the save's own rule whether a field becomes a column, `fieldProducesColumn`, which `nextly/config` publishes with `usesJunctionTable` (both @experimental). The field picker's `nameProblem` is also told the type picked (`(name, type)`), an additive change to the experimental plugin SDK type. A schema template's name check asks the same rule, so a link to several entries, which keeps them in a column of its own, is now held to a column's length there as the save holds it.
