The font catalogue route answers the standard `{ items, meta }` list, with where previews load and when the catalogue was read in its meta. Adding a font reads its request body up to 8 KB and no further. An uploaded font file whose family the site cannot store is refused before the file is stored, and the next variable font starts from the full 100 to 900 range.
