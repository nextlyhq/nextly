A page save is now held to the limits the site configured in the page builder's `limits` option, the same ones its pages are drawn under, instead of the engine's defaults. A site that set a tighter depth or block count can no longer save a page past it, and a site that set looser limits can save pages the defaults refused. The custom CSS on every block within those limits is checked and recorded too.
