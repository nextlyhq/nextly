While a component is edited on its own, a block's data picker lists "This component's settings" first, each setting with its default beside it, then the Singles and the site, folded. Only settings the prop can follow are listed, by the same rule the save judges a follower by, which `@nextlyhq/blocks-engine` now exports as `followableSettingsOf` (`@experimental`). A pick binds the block to the setting. A line above the settings says how many pages use the component, as its view counts them ("Used on 4 pages"). A prop bound to a setting names it on its chip and offers no fallback, since the setting always gives it a value.
