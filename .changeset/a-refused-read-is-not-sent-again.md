The admin no longer sends a refused read a second time. A read the server answers with a 4xx status, such as 401 while signed out, 403, 404 or 422, is shown at once; a timeout (408), a rate limit (429), a server error (5xx) or a lost response is still sent once more. The signed-out sign-in screen asks for the general settings once rather than twice.
