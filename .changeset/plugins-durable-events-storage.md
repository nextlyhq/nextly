Core adds the storage for durable plugin events: two new tables, `nextly_plugin_events` and `nextly_plugin_event_deliveries` (one delivery per event and subscriber), which `nextly migrate` adds to an existing database. A plugin may now declare an event `durable: true` in `contributes.events`; startup refuses a `durable` flag that is not `true` or `false`. Emitting and delivering durable events come in later releases. Experimental.
