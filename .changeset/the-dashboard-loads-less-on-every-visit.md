The dashboard loads about 70 KB less on every visit, and every admin page's first load is lighter. A dashboard card's settings panel, which draws its form with the entry editor's fields, now loads when a reader is about to open it, as the pointer comes over or focus reaches the card's menu, its quick popover's More settings or its empty state's button, rather than with the dashboard itself. The upload tray in the media library and the upload drop area loads as it appears, and the code the admin loads before any page draws no longer carries the dashboard's drag-and-drop or every release query. Nothing looks or works differently.
