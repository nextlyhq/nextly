The Schema Builder can ask, before creating a collection, Single or field group, what the create would answer for an address: one route per kind (`POST /api/collections/schema/address-check`, `/api/singles/schema/address-check`, `/api/field-groups/schema/address-check`), gated by that kind's create permission, which runs the create's own checks and counts the entities created in the editor but not saved yet. A Single or field-group create sent without an address now answers with the address rule's "required" refusal (400) instead of an internal error.
