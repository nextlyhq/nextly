In the page builder's Design panel, a font variable is now chosen from a picker of the site's fonts and the system font stacks, the same picker a block's Font uses, rather than typed. A weight variable is chosen by name, from "Thin 100" to "Black 900", with the weights the site's fonts have listed first and the others marked "No font on this site has this weight". The font picker's link to the site's fonts now reads "Manage fonts…", in the block panel too. From Design it opens the Type tab's Fonts group, unfolding it if it was folded.
