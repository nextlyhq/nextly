On MySQL, a role assignment counts for its user whatever case the assignment's row spells the user's id in, as MySQL itself compares ids.

A user's role assignments are read for several users in one statement and then matched to each user in code. That match compared ids exactly, so a row that MySQL's statement matched, spelling the id in another case, was dropped along with the role it grants. A super-admin assigned that way was not counted, and the last super-admin could be deleted. PostgreSQL and SQLite compare ids exactly, and the match stays exact there.
