New API keys carry a public id: `nx_live_<id>_<secret>`, where the 24-character id holds a tag only this install can make. From a client whose address the server cannot resolve (the default without `security.trustProxy`), a key's failed lookups are now bounded per verified id before any lookup, so a flood of invalid keys can no longer refuse a valid key that carries an id. Keys made before ids keep working under the shared bound as before; replace one with a new key to get the per-key bound. The key's display prefix now names its id rather than the first characters of its secret.
