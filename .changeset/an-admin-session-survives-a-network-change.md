An admin session no longer ends when the browser's network address changes. With `security.trustProxy` on, as on Vercel, a refresh from another address than the last one signed the editor out and ended the account's sessions on every device, which happened within half an hour of signing in on networks that send each connection out through a different address. The refresh now goes through and logs a `refresh-client-changed` warning instead. A page a browser opens without a usable session, such as Search Console's return from Google after the session expired, now goes to the sign-in page, which refreshes the session or asks you to sign in and then opens the page again, instead of showing a raw error.
