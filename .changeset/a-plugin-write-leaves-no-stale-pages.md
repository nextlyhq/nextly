A plugin that writes to columns it added to a collection, a Single or a component through `ctx.db.contributed` now expires the cached pages showing that entry or Single, as any other content write does. Inside `ctx.db.transaction` the pages expire once the transaction commits, and a rolled-back write expires nothing. A cached page also keeps its own collection's or Single's tag when a read names more tags than Next.js keeps. On SQLite, a collection or Single deleted inside `ctx.db.transaction` expires its cached pages once that transaction commits, and not at all when it rolls back; on PostgreSQL and MySQL that delete commits on its own connection, so it expires them straight away and a rollback does not undo it.
