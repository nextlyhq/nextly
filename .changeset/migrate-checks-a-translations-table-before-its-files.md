`nextly migrate` checks a translations table before it applies the files `migrate:create` wrote for it. The table is compared with what the applied files of that entity left: whether it is there, and each translated column by name and type. A difference made outside a migration is reported as drift, naming the file, the table and each difference, and nothing is applied, as for any other generated file. These files are no longer announced as applied "without drift checks". Where a translations table was not made by a migration file, so there is nothing to compare it with, its files are applied and one line says why. A migration written by hand, which has no snapshot, is still said to run without drift checks.
