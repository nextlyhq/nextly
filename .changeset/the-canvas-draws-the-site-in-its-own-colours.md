The page builder's canvas draws the page in the site's own colours and type whatever theme the admin is in: with the admin in dark mode a white site no longer appears black with light text, the page is set in the site's body font rather than the admin's, the page's form controls and scrollbars follow the site, and a site that darkens with the visitor's system is shown dark on the canvas when the system is dark. The editor's marks on the page are clearer too: a selected block has a blue ring with a white halo that reads on light, dark and coloured sections, the drop line uses the same blue, a selected component placement is purple, and the block toolbar is a dark bar with light text in both admin themes.
