Page builder: a template row can no longer commit linked (`forkedFrom`) to a template deleted while it was written. Every write that sets or changes the link holds that template's row on its own transaction and is refused once the template is gone, whichever path wrote it, so the Direct API is covered as well as giving an entry its own design. Deleting a collection also removes its entries' own designs before its template, so those designs are no longer updated, with their hooks, history and events, just before they are deleted; a copy of the template in another collection still has its link emptied.
