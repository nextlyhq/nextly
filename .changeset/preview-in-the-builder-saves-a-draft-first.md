Preview in the page builder now shows what the canvas shows. With unsaved changes the button reads "Save and preview": it opens the tab at once, saves a draft (never publishing; on a published page the edits wait in its working draft), then shows the preview there. If the save fails, the tab closes and the reason is shown. Where no save would keep the page unpublished, the button reads "Preview the saved version". For plugin authors, `useDocumentActions()` gains `saveWithoutPublishing`, and `useDocumentPreview().open()` takes an optional step to run once the preview's tab is claimed.
