Version retention now keeps, whatever `versions.maxPerDoc` says, the latest published version of each language and of the shared part, judged by the parts each version records it changed. A publish of chosen parts, or of every language, carries no single language, so publishing English alone, then Spanish alone, and then saving past the cap could remove English's latest published version; it is now kept. Versions recorded before versions named their parts keep the previous rule (the latest published version of each language and the latest with no language), and a newer version never takes one of their places, so none of them loses the protection it had. Named versions, restores and their sources, and pinned versions are kept as before.
