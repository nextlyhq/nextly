A blog scaffolded with the visual approach builds on its first `nextly migrate` again. Its migration now creates the tables in the layout every installation keeps: each collection's and Single's translatable fields in its translations table (`<table>_locales`), a slug unique within each language, and the Site Settings and Homepage defaults in their default-language rows. It created them on the main tables before, so the first `nextly migrate` of a fresh blog asked for a confirmed backup to move values it had only just written, and stopped without a terminal.
