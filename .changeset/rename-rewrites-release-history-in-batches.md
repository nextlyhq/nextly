Renaming a collection or Single in the Schema Builder is now quick on a long release record. The rename rewrote each stored JSON value that named the old slug in a statement of its own, inside the rename's transaction: every event in a release's history about one of the entity's documents, every webhook filter listing it. JSON values are now written many rows to a statement, so the number of statements no longer grows with the number of events, on PostgreSQL, MySQL and SQLite alike. The rename now reads, from release history, only the events about a document.
