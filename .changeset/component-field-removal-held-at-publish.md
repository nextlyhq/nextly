Publishing a component that removes an exposed field now counts again: when
more documents place the component than the removal dialog said, the editor
asks again with the new count before anything goes live. While the removal is
held for its publish, a write that newly sets one of the removed fields on a
placement of the component is refused, saying the field is being removed, so
the count the designer confirms is the one that loses a value.
