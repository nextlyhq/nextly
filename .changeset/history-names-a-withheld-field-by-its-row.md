A version read now names a field it withheld inside a list by that row's index in the version (`items.1.secret`), not by the list alone (`items.secret`). A read rule that reads its row can allow a field in one row of a repeater or repeatable component and deny it in another, and the old path hid the field in every row. A comparison now hides the field only in the row each version withheld it in, so the other rows' changes to that field still show. The shape of `withheld` is experimental: a client that matched list fields by the row-less path should match the indexed one.
