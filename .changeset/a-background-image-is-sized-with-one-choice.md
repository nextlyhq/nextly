A block's background image is sized with one choice. In the Style tab's Background section, Size offers Cover (fills the block, cropping the edges), Fit (the whole image, once) and Tile (the image at its own size, repeated). Each choice sets the background repeat with the size in one edit, so Fit no longer tiles the image and one undo takes both back. Any other size can still be written as CSS, and reads "Custom".
