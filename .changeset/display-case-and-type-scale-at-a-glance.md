The Style tab shows four more choices the way an author makes them. Display
is Block, Flex, Grid and None as icons, with the inline modes, flow root and
list item under More. Text case is None, Uppercase, Lowercase and
Capitalize as icons. A font size's menu offers the site's type scale above
its units, and choosing a size stores a reference to it. The values under an
icon group's More read in words, and where an inherited value comes from
shows in full rather than cut short.
