Creating a collection, Single or field group in the Schema Builder no longer writes it at once: Create opens its editor with the entity unsaved, its starting field and any fields added since shown as pending changes, and its first save creates it. That save is reviewed as what will be created, checks the address once more, and keeps the entity unsaved if the create is refused. Leaving the editor or discarding its changes before that save lets the entity go, with nothing written. A saved collection or Single laid out from blocks offers to open the Page Builder.
