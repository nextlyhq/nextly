A Schema Builder save of a collection, a Single or a field group that fails while writing its registry row now leaves the save as it was. The registry row is written in the same transaction as the save's migration, so on PostgreSQL and SQLite a failed write rolls the change back and withdraws the save's files, and the save answers that it failed. Before, the change stayed applied while the registry still described the old shape, and a collection's or Single's save answered that it was applied.
