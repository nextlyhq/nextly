`@nextlyhq/ui` now writes its declarations from the type annotations in its own source, one file at a time, instead of running the type checker over the package. The JavaScript it publishes is unchanged, and so are the types of every export but four: `Sheet`, `SheetHeader`, `SheetFooter` and `ContextMenuShortcut` are now typed as `React.FC`. Using them in JSX is unaffected. Called as plain functions, they are typed to return `ReactNode` rather than `JSX.Element`, and their `displayName` is optional.
