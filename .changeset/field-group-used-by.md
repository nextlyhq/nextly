A field group's editor in the Schema Builder now says which collections, Singles and field groups use it, each linked to its own editor, and that a change there reaches all of them; it says so when that cannot be read, rather than showing nothing. In the outline, a field that uses a field group shows how many places use it. The answer comes from a new read, `GET /api/field-groups/<slug>/used-by`, which lists each field that places the field group with the collection, Single or field group holding it; like reading the field group itself, it needs a signed-in user and no specific permission. The field-group list's use count is now the length of that same list.
