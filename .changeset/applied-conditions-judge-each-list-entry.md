With Apply conditions on, the canvas now judges a block that a list's entry decides for each entry it draws, as the published page does. While the switch is on, the canvas reads its lists as a visitor would: published entries and public fields only, and only for a document the person editing may open. A block an entry hides is drawn as a marker in its place that says why, and the Previewing count no longer treats such blocks as unchecked. With the switch off, the canvas shows the person's own rows again, drafts included. Published pages are unchanged: a block an entry hides is still left out. `PageRenderer` takes an experimental `itemHiddenAs` for an editor to draw in that block's place.
