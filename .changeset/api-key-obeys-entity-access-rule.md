A scoped API key reaching a collection or single through a permission-gated route, including plugin routes that declare `requiredPermission`, is now held to that entity's code-defined `access` rule. Previously holding the grant was enough on these routes, while the collection routes already applied the rule. A key the rule refuses now receives 403 where it was admitted.
