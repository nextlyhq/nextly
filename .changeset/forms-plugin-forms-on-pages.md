The Forms plugin's forms can be placed on page builder pages. With the page builder installed, the plugin offers its forms to the Form block through the page builder's form provider service (an experimental contract): the block lists them, draws the picked one on the server, and a visitor's plain HTML form post runs the same validation, storage, emails, spam checks and one-response rules as the plugin's JSON address, which is unchanged. A form with a bot check loads the plugin's own small script only on pages that draw it.
