A collection can be closed to super-admin (`@experimental`): `closedToSuperAdmin: true` on its definition, or from the super-admin role's page in the admin for a collection whose code says nothing. Its entries are then refused to every super-admin and every full-access key with super-admin authority, at every way in, whatever else they hold; trusted server code is unaffected. Changing the mark in the admin asks for the password again, and every change, from the admin or from code, is written to the audit log with who, when, and the value before and after. Nothing changes for a collection that is not marked.
