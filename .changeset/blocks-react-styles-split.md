`@nextlyhq/blocks-react`'s page styles now live in modules that each hold
one part: the stored style artifact, what a compile reads from the page's
blocks, whether a stored artifact can be served, the condition-gated
rules, and what a render compiles with. The package exports the same names
and pages are styled the same. `resolvePageStylesWithTrace` now carries
its doc comment in the published types.
