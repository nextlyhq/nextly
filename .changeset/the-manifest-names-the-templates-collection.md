The page builder's composition manifest (`GET /manifest`) now names the templates collection as `collections.templates`, under the slug the host gave it, so an API client or agent can address a collection's template and an entry's own design with the page actions using only what the manifest says. The field is additive: the manifest's `formatVersion` stays 1, and `compositionManifestSchema` now expects it. The guide to composing through the API now covers building a template end to end, with lists, bindings and conditions, and the `set-template-address` action and the permission it needs.
