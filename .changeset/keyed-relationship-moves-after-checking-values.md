Pointing a Schema Builder relationship whose column holds a foreign key at another collection now moves the key there, on PostgreSQL, MySQL and SQLite. Every value is checked against the new collection before anything runs; if an entry holds a value the new collection does not have, the save is refused naming the field and how many entries are in the way, and the old key stays. The new key is added under a name of its own before the old one is dropped, so a failure part-way on MySQL leaves the relationship keyed. A target with no table a key can check (a Single, or a slug that names nothing) is refused. Any key added over a column that already holds values is judged against its rows the same way.
