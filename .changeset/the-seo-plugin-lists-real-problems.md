The SEO plugin lists real search problems under SEO › Problems: each public page is checked for a missing, shared or overlong title or description, a canonical naming another address, a broken internal link, a missing or wrongly sized share image, images with no alt text, structured data missing a detail and a language code search engines refuse, and the site for a missing production address, a collection with no public address, a redirect that takes more than one hop and a page left out of the sitemap. Each problem links to its fix, a saved page is checked again, and the whole site when the list is a day old or someone asks; serving a page runs no check, and there is no score.
