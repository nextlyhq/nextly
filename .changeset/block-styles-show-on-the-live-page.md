Block styles chosen on the canvas now show on the published page and in the draft preview. A Section's Hero, a Button's Secondary, Outline or Text, an Image's Rounded or Circle, and the styles other plugins' blocks offer were drawn on the canvas but left off the live page, because the site style a published route loads held none of them. `loadSiteStyle` now adds every registered block's styles, the same set the canvas uses; a host changes nothing. Pages that already wear one of these styles start showing it.

When a block uses a style the site doesn't have, the style compiler's warning now names the style and says what to do about it, in plain words.
