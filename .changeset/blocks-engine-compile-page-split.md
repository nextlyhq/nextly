`@nextlyhq/blocks-engine`'s page compiler module, `style/compile-page.ts`, is split into parts by what each does: the compile context and its result, the interaction states, breakpoints and preview containers, the rules a style envelope compiles to, and the nodes compiled and the layout each container gives its children. The module keeps its doc and `compilePageCss`, and re-exports every name it exported before, so imports, behaviour and the compiled CSS are unchanged.
