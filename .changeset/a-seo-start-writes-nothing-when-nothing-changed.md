The SEO plugin no longer rewrites its bookkeeping at every start. The start-up catch-up of the address record is skipped whenever the address templates, the site's content types and the pending moves are unchanged since its last run, including on a site where no page holds an address yet, and a run that finds a stored note already current leaves it as it is. The note that the site's Proxy runs is written only when the stored one is an hour old or more, so a server's first request after a start writes nothing within that hour.
