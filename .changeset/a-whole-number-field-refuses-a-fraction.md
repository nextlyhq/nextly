A fractional value written to a whole-number `number` field used to be
decided by the database: MySQL silently rounded it, PostgreSQL answered a
500, SQLite stored it as written. The entry write validation now refuses
the fraction with a validation error naming the field — before any write,
identically on every dialect, on create, update and bulk, and on hasMany
list elements. Fields declared with `dbType: "decimal"` or the float format
keep accepting fractions, and values already stored are untouched: a legacy
fractional row keeps reading and publishing unchanged.
