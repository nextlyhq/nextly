Publishing a language other than the default from the admin's "Choose what to publish" dialog works again, as does publishing from any read of every language. A read of a document with `locale=all` answered a version (`_rev`) naming the default language alone, so a write of another language made from it was refused with "\_rev names no version of es". Its version names every language of the site again, in a collection, a list and a Single. A read of one language answers the version it always did, and a write made from an out-of-date version is refused as before.
