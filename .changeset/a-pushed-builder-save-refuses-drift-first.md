A Schema Builder save that applies its change directly in development (a relationship storage switch, a Single or field-group save that carries values, a translated collection's change) now checks the table against the migration history before it changes anything. Where a column was added by hand, or the table otherwise differs from what the history records, the save is refused with `NEXTLY_MIGRATION_DRIFT` naming each difference, and nothing is changed or written. Before, the change ran first and the save was refused afterwards, leaving the table changed and its migration files unrecorded.
