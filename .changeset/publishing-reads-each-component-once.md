Publishing or saving a page now reads the components it places in one query for each form, instead of a few for each component, so a long page answers faster, most of all against a remote database. Publishing one text change of a page placing ten components went from about 120 database statements to under 75 on SQLite, PostgreSQL and MySQL, and the count no longer grows with the number of components. Field validators and in-transaction handlers can read one stored field of several entries at once with the new experimental `readStoredOf`, which follows the same access and language rules as `readStored`.
