Removing a variable or a shared style while a page is saved can no longer leave that page using something the site does not define. Whichever finishes first wins: a page saved first makes the removal refuse it as in use, with nothing removed; a removal finished first makes the page save refuse its new use. Every way of removing one is covered, including saving the whole Variables section, an undo and an import. If the site styles cannot be checked in time, the save or removal is refused with a message to try again. A removed variable is no longer briefly taken out and put back when a page started using it during the removal.
