A new package, `@nextlyhq/mcp`, turns the operations marked for agents into MCP tools through one adapter, ready for both MCP doors: each tool's name (verb first, checked against the adapter's table), title, description, JSON Schemas and all four hints come from its operation, and each answer is Markdown with admin links, the same data as a fenced JSON block, and structured content checked against the output schema, concise by default, paged by an opaque cursor and capped at 50,000 characters. Refusals are tool errors that name core's error code, say what to do next and suggest close names. The package is private until its first release; no tool an agent sees changes yet.
