A Single read or saved for the first time by two requests at once no longer fails one of them. On a fresh site, the first page views reading a Single that has no document yet (such as a plugin's settings) could each try to create it, and on PostgreSQL and MySQL one failed with a duplicate key error. Exactly one document is now created, with its defaults, first version and "created" history event written once, and every request gets it.
