A Schema Builder save that changes a saved field's type is now judged against the values its column holds, before anything runs, on every save road (the push, the writer, a Single's own save). A change that would cut or round a value is refused (`TYPE_CHANGE_BLOCKED`); one that would clear a value the new type cannot read is refused unless the owner consented for that field (`TYPE_CHANGE_LOSES_VALUES`). Each refusal names the field, both types and the rows by key, never the value, and reaches the admin by field and code. Code-first applies (`db:sync`) are unchanged.
