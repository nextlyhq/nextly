**Upgrading a SQLite site that has form submissions: wait for the next alpha.** This release keeps translatable text in per-language tables. On SQLite, upgrading an existing database that holds form-builder submissions drops six of their fields (spam reason, notes, IP address, user agent, edited by, title) before their values are copied, so those values are lost. PostgreSQL and MySQL upgrades are not affected, and a new SQLite site is not affected. The next alpha fixes the SQLite upgrade. Until then, keep a SQLite site with form submissions on its current version, and back up any database before upgrading.
