Draft previews no longer need an API key. A preview token names exactly one entry and
carries no other authority: it grants a draft read of that document and nothing else, expires
on a short timer, and every outstanding link can be revoked at once without touching anyone's
session.

The signing key is derived separately from the session key, so a preview link cannot be
presented as a session cookie and a session cannot be presented as a preview link. That holds
by arithmetic rather than by remembering to check a claim on every path.
