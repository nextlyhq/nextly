Page builder: the page status pill reports the saved page only (Draft, Published or Changed), so unsaved edits are said once, by the save chip. Changes from a last visit that were stored but never saved now open with Save enabled and the chip saying "Changes from your last visit aren't saved yet", with Save, which keeps them, and Discard.
The plugin SDK exports `savedPillState`, the entry page's status rule, for a plugin's own status pill.
