`nextly migrate` now adds the permissions and roles a database lacks and sets the preset roles' grants, under the schema lock, once its migrations and registry rows are in place. It adds Nextly's own permissions, each collection's and Single's, the ones the config declares and each plugin's, and the roles plugins declare, then brings Admin, Editor, Author and Viewer to what their presets grant by difference. A database set up by `nextly migrate` alone now has an Admin role holding every permission its preset grants before any start, and a run with nothing to add or change writes nothing to the permission, role or grant tables. The run marks no permission as undeclared, and a start still seeds as before.
