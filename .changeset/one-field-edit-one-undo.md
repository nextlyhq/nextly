One edit to a field in the builder is one step to undo, and Escape in a field being edited puts back the value from before the edit, in the field and on the canvas, recording nothing; a second Escape leaves the field with the block still selected. The editor state gains `cancelTyping(run)` (experimental), which takes back a run of typing that writes as the author types, with the history as it was before the run.
