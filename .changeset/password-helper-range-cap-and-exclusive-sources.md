The plugin password helper's breached-password check now reads a range answer only up to 256 KiB. A larger answer leaves the password unchecked rather than being read whole into memory. A `security.breachedPasswords.source` that names both a `url` and a `range` is now refused by the configuration schema. At runtime it asks neither, and startup warns about it.
