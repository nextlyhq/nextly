The page builder remembers the fields a component stops exposing. When a component
definition that drops an exposed field or slot is published, the field's id is
retired: it is recorded in a plugin-owned table, never minted again, and every later
write of a page, a Single or another component takes that field's placement values
out before validation. A component save also drops its own retired fields from its
`exposed` list, its slots and its variants, so restoring an earlier version cannot
bring a removed field back. A draft save retires nothing: live pages keep the values
the published definition still shows.
