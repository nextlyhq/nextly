When a configuration imports a path inside an installed package that Node cannot load as
written, such as `next/headers` from a package with no `exports` map, `nextly` commands no
longer say the package is not installed. They name the package as installed, say the path
needs its file extension, and give the import Node suggests (`next/headers.js`). A path the
package has no file for is named as that.
