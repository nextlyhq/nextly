A role or API key holding `manage-media`, `manage-settings`, `manage-email-providers` or `manage-email-templates` now passes every gate that asks read, create, update or delete on that same resource: a route asking one permission or any of several, `ctx.caller.can`, a dashboard widget's or a document lock's required permission, the schema builder's collection list, and the system-resource reads. The access decision already counted it, but these gates did not, so a holder of `manage-email-providers` was refused a route asking `update-email-providers`. It never counts as publish or unpublish, as any other action, or on any other resource.
