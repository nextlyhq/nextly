A collection or Single can declare where its pages are served with `publicAddress` (`"/blog/{slug}"`, or `"/about"` for a Single), judged by one rule when the configuration loads. `publicAddressOf(type, entry, locale)` answers an entry's address from that declaration, and `typesWithoutAddress()` lists the types with none yet. A type made in the Schema Builder has its address supplied by a plugin through the `publicAddress.template` filter, judged by the same rule; a type declared in code never asks a plugin. Both functions are experimental.
