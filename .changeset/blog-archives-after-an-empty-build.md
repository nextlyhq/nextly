The blog template's category and tag pages no longer answer 500 on a site built before it had any categories or tags. Both an unknown archive and one created after the build failed, because Next.js took the archive routes for static when the build rendered none of them. The build now always renders one, so it learns the pages read the request. An unknown archive shows the not-found page, and one added after the build lists its posts, page 2 included.
