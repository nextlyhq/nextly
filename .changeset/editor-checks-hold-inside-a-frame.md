The page builder checks what kind of element it is handling, and which element has focus, in a way that also holds for an editor canvas running inside a frame. Nothing changes for authors yet; this prepares the canvas to move into a frame. `@nextlyhq/builder` also exports `deepActiveElement` and `isHTMLElement` (experimental) for hosts that read focus or check elements around such a canvas.
