User custom fields are added through the shared field picker (search, then a label that names the field) and edited in the shared settings panel, configured for user fields: a dropdown's and radio group's choices, a checkbox as one yes or no, a default typed as text for URL, phone and plugin types, only the bounds a user field stores, no conditions, and the name, type and a dropdown's "several choices" shown fixed once the field exists, with the reason. Before a new field is created its type can still be changed. The pages keep their own save, the reserved-name and choice checks, the Active switch and the list's reordering.
