Selecting a block in the page builder no longer redraws the left rail, Help or Page settings: each is drawn again only when something it shows changes, such as a panel opened, the panel keys turned off, or an edit or rename of the page Settings shows. For plugin and field authors, `useDocumentIdentity` now returns the same object while the document is the same, so a value memoised over it keeps its identity across renders of the form.
