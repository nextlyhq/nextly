When a component's published definition drops a field or an exposed slot, the
values pages still hold for it are now taken out of every document, not only
the ones saved afterwards. A background sweep (`page-builder:retired-cleanup`)
walks published pages, their working drafts, Singles, other components and
patterns, in every language, writing each one only if nobody changed it in
between. A save that raced the walk is walked again once it commits. A live
row under a pending working draft keeps its value until that draft is
published, which then puts the stripped draft live.

The strip on every write now also reaches blocks fields inside named groups.
