The command palette's `CommandSeparator` no longer breaks the accessibility tree of the list it sits in. The list is a listbox, which may hold only options and their groups, and the divider was a separator inside it, so a screen reader met a child the list should not have and axe-core's "aria-required-children" check failed. The divider is now hidden from screen readers by default and still drawn as the same 1px line, so the admin's Ctrl+K palette, the Page Builder's header and footer menu and any plugin using it are fixed without a change. A separator placed outside the list can be announced again with `aria-hidden={false}`.
