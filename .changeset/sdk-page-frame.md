Plugins can draw their admin pages from the pieces core pages use. `@nextlyhq/plugin-sdk/admin` now exports `PageFrame`, which takes the page type (`list`, `form`, `editor` or `workspace`) that decides its width, and `PageHeader` with `PageTabs` and `PageTab`, all experimental. A plugin page that draws no `PageFrame` is drawn as a Workspace page inside the admin shell, full width with no gutter and no padding, and a page that draws its own frame is not framed a second time and takes the vertical spacing a core page of its type has.
