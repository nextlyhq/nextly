---
title: PLUGIN_EVENT_OUTSIDE_NAMESPACE
description: "A plugin declares an event whose name does not start with the plugin's prefix."
---

## Cause

A plugin declares an event whose name does not start with the plugin's prefix.

A plugin's declared events are named under its admin slug, so no two plugins emit the same event. The message names the prefix the event must start with.

## Fix

- Rename the event so that it starts with the prefix the message names.

## Example

```text
✗ Plugin "reviews" declares the event "review.created", which must start with "reviews.".
  Why:  A plugin's events are named under its admin slug, so no two plugins emit the same event.
  Next: Rename the event "review.created" so that it starts with "reviews.".
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-event-outside-namespace  (PLUGIN_EVENT_OUTSIDE_NAMESPACE)
```
