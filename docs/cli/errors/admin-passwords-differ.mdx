---
title: ADMIN_PASSWORDS_DIFFER
description: "The two passwords typed at the prompt differ."
---

## Cause

The two passwords typed at the prompt differ.

At a terminal the password is asked for twice, to catch a typing mistake in a value that is not shown. The two answers were not the same, so nothing was created.

## Fix

- Run `nextly users:create-admin` again and type the same password both times.

## Example

```text
✗ The two passwords differ, so nothing was created.
  Why:  The password is asked for twice, and the two answers must match.
  Next: Run `nextly users:create-admin` again and type the same password both times.
  Docs: https://nextlyhq.com/docs/cli/errors/admin-passwords-differ  (ADMIN_PASSWORDS_DIFFER)
```
