---
title: PLUGIN_SECRET_PATH_DUPLICATE
description: "A plugin declares the same secret path twice."
---

## Cause

A plugin declares the same secret path twice.

Each setting is encrypted once, so each path in `capabilities.secrets` is listed once.

## Fix

- Remove the repeated path from `capabilities.secrets`.

## Example

```text
✗ Plugin "reports" declares the secret path "apiKey" twice.
  Why:  Each setting is encrypted once, so each path is listed once.
  Next: Remove the second "apiKey" from `capabilities.secrets`.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-secret-path-duplicate  (PLUGIN_SECRET_PATH_DUPLICATE)
```
