---
title: PLUGIN_SECRET_PATH_NOT_STRING
description: "A plugin's secret path names a setting whose value cannot be a string."
---

## Cause

A plugin's secret path names a setting whose value cannot be a string.

A secret is stored encrypted, as a string, so its setting must hold one. A number or a boolean setting would fail on every save.

## Fix

- Point the secret path at a text setting.
- Or make the setting it names a string.

## Example

```text
✗ Plugin "reports" declares the secret path "retries", which names a value that cannot be a string.
  Why:  A secret is stored as a string.
  Next: Point "retries" at a text setting, or make the setting it names a string.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-secret-path-not-string  (PLUGIN_SECRET_PATH_NOT_STRING)
```
