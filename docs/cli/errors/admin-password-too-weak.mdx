---
title: ADMIN_PASSWORD_TOO_WEAK
description: "The administrator's password does not meet the install's password rules."
---

## Cause

The administrator's password does not meet the install's password rules.

The first administrator's password is held to the same rules as setup's, including the minimum length the configuration's `auth.minPasswordLength` sets. The Why line names each rule it breaks.

## Fix

- Choose a password that meets each rule listed, then run `nextly users:create-admin` again.

## Example

```text
✗ That password is too weak, so nothing was created.
  Why:  Password must be at least 12 characters
  Next: Choose a password that meets each rule listed, then run `nextly users:create-admin` again.
  Docs: https://nextlyhq.com/docs/cli/errors/admin-password-too-weak  (ADMIN_PASSWORD_TOO_WEAK)
```
