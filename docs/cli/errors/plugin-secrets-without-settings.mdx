---
title: PLUGIN_SECRETS_WITHOUT_SETTINGS
description: "A plugin declares secret paths but no settings schema."
---

## Cause

A plugin declares secret paths but no settings schema.

A plugin's `capabilities.secrets` lists the settings to store encrypted. Without a settings schema under `contributes.settings`, the paths name nothing.

## Fix

- Add the settings schema under `contributes.settings`.
- Or remove `capabilities.secrets`.

## Example

```text
✗ Plugin "reports" declares secret paths but no settings schema (contributes.settings) for them to name.
  Why:  A secret path names a setting to encrypt, so without `contributes.settings` it names nothing.
  Next: Add the settings schema under `contributes.settings`, or remove `capabilities.secrets`.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-secrets-without-settings  (PLUGIN_SECRETS_WITHOUT_SETTINGS)
```
