---
title: NEXTLY_CORE_UPGRADE_INCOMPLETE
description: "A core upgrade ran, but Nextly's own tables still lack a column or table this version declares."
---

## Cause

A core upgrade ran, but Nextly's own tables still lack a column or table this version declares.

After its push, `nextly migrate` checks that every core table has every column this release declares. If one is still missing, it stops here, naming each one, rather than report the upgrade as done and leave a feature to fail later on a column that is not there.

## Fix

- Run `nextly migrate` with the release the message names first, for example `npx nextly@0.0.2-alpha.65 migrate`, against the same database.
- Then run this version's `nextly migrate`. Running it again changes nothing that is already in place.

## Example

```text
✗ The core upgrade ran, but Nextly's own tables are not up to date.
  Why:  The core upgrade ran, but Nextly's own tables still lack what this version declares (dynamic_collections: revalidate, webhooks).
  Next: Run `npx nextly@0.0.2-alpha.65 migrate` first, then this version's `nextly migrate`.
  Docs: https://nextlyhq.com/docs/cli/errors/nextly-core-upgrade-incomplete  (NEXTLY_CORE_UPGRADE_INCOMPLETE)
```
