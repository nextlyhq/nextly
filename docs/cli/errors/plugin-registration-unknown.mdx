---
title: PLUGIN_REGISTRATION_UNKNOWN
description: "`nextly plugins add` cannot tell how to register a package: it declares nothing, and its entry exports no single plugin."
---

## Cause

`nextly plugins add` cannot tell how to register a package: it declares nothing, and its entry exports no single plugin.

A package with no `nextly.plugin` declaration is registered by the one plugin definition its entry exports, as it is. This package's entry exports none, or more than one. A function that makes a plugin is not called to find out, since what it needs and what calling it does are the package's to say.

## Fix

- Add the plugin to `plugins` in `nextly.config.ts` as its README shows, then run `nextly plugins install <name>`.
- A plugin author can add a `nextly.plugin` declaration so the command registers it: see [Declaring how a plugin is added](/docs/plugins/distribution#declaring-how-a-plugin-is-added).

## Example

```text
✗ Nextly cannot tell how to register "@acme/seo".
  Why:  It has no `nextly.plugin` declaration, and its entry exports no plugin definition as it is; a function that makes one is not called to find out. A package that declares nothing is registered by the one plugin its entry exports.
  Next: Add it to `plugins` in nextly.config.ts as the package's README shows, then run `nextly plugins install` with the plugin's name.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-registration-unknown  (PLUGIN_REGISTRATION_UNKNOWN)
```
