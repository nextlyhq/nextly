---
title: CONFIG_TOOLING_UNAVAILABLE
description: "Reading the configuration needs the optional `esbuild` package, which is not installed."
---

## Cause

Reading the configuration needs the optional `esbuild` package, which is not installed.

The CLI, and the app in development, compile `nextly.config.ts` with esbuild. It is an optional dependency, so a production install without development dependencies can leave it out.

## Fix

Install it as a development dependency, then run the command again:

```bash
pnpm add -D esbuild
```

In production it is needed only when `db.runMigrationsOnBoot` is on.
