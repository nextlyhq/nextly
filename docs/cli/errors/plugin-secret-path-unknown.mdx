---
title: PLUGIN_SECRET_PATH_UNKNOWN
description: "A plugin declares a secret path its settings schema does not contain."
---

## Cause

A plugin declares a secret path its settings schema does not contain.

A secret path the settings schema does not contain would match nothing, so the credential it was meant for would be stored in plain text and printed unredacted.

## Fix

- Correct the path to the path of a setting in `contributes.settings`.
- Or add that setting to the schema.

## Example

```text
✗ Plugin "reports" declares the secret path "apiKey", which its settings schema does not contain.
  Why:  A secret path the schema does not have would leave the credential it is for stored in plain text.
  Next: Correct "apiKey" to the path of a setting in `contributes.settings`, or add that setting.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-secret-path-unknown  (PLUGIN_SECRET_PATH_UNKNOWN)
```
