---
title: LEGACY_BOOKKEEPING_FOUND
description: "The database still has the migration bookkeeping tables of an earlier Nextly release."
---

## Cause

The database still has the migration bookkeeping tables of an earlier Nextly release.

Earlier releases recorded migrations in `nextly_migrations` and `nextly_migration_journal`. This release keeps that history in `nextly_schema_events`. `nextly migrate` moves the old tables into it once a backup is confirmed; every other command that needs the history stops with this code until it has.

## Fix

- Back up the database.
- Run `nextly migrate --backup-confirmed` once. It moves the old history into `nextly_schema_events` and carries on with the pending migrations.
- Then run the command again.

## Example

```text
✗ Legacy bookkeeping tables detected (nextly_migrations).
  Why:  They hold the history an earlier release recorded, which this release keeps in `nextly_schema_events`.
  Next: Back up the database, then run `nextly migrate --backup-confirmed` once to move them into nextly_schema_events before continuing.
  Docs: https://nextlyhq.com/docs/cli/errors/legacy-bookkeeping-found  (LEGACY_BOOKKEEPING_FOUND)
```
