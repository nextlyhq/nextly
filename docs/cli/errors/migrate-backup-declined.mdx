---
title: MIGRATE_BACKUP_DECLINED
description: "`nextly migrate` found the migration records of an earlier Nextly release, and its backup question was answered no."
---

## Cause

`nextly migrate` found the migration records of an earlier Nextly release, and its backup question was answered no.

Earlier releases recorded migrations in `nextly_migrations` and `nextly_migration_journal`. `nextly migrate` moves those records into `nextly_schema_events` and drops both tables, so it asks whether the database is backed up first. At the prompt the answer was no, so nothing was changed.

## Fix

- Back up the database.
- Run `nextly migrate` again and answer yes, or pass `--backup-confirmed`.

## Example

  Next: Back up the database, then run `nextly migrate` again and answer yes, or pass `--backup-confirmed`.
