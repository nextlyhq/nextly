---
title: CREATE_STORAGE_TAKEN
description: "A field group or Single would be created over tables, views or field-group rows that nothing registered owns."
---

## Cause

A field group or Single would be created over tables, views or field-group rows that nothing registered owns.

Before it builds anything, a field group's or Single's create checks the tables it would use. An empty table an earlier attempt left behind is replaced. It refuses instead, and changes nothing, when what stands there is not its own to replace: a table that holds rows, a leftover table other tables reference, a table standing where it would build one of its own, or, for a Single, rows in the shared field-group tables that still name its table as their parent, whether or not the table itself still stands. On PostgreSQL, a view reading the tables it would replace refuses it too. The message names each one.

## Fix

- Check the tables the message names. If they hold data you need, back it up first.
- For a table that holds rows, or one standing where the create would build, drop or rename it, then retry the create.
- For a leftover table other tables reference, drop those tables or their references to it, or rename the leftover table itself, then retry the create. Renaming a referencing table is not enough: under its new name it still references the leftover.
- For rows in a shared field-group table, delete the rows the leftover left there: those whose `_parent_table` is the leftover table, and every row nested beneath them, which names its parent row instead. Then retry the create. Keep the table: it belongs to a field group and holds other entities' rows.
- For a view, drop it, or redefine it to read other tables, then retry the create. Renaming a view is not enough: under its new name it still reads the same tables.

## Example

```text
✗ Creating the Single "home" was refused.
  Why:  "single_home" (3 rows) already exists and holds rows, but nothing registered describes them.
  Next: Drop or rename those tables, then retry the create.
  Docs: https://nextlyhq.com/docs/cli/errors/create-storage-taken  (CREATE_STORAGE_TAKEN)
```
