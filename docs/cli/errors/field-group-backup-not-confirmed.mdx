---
title: FIELD_GROUP_BACKUP_NOT_CONFIRMED
description: "`migrate:field-groups --apply` was run without `--backup-confirmed`, so it changed nothing."
---

## Cause

`migrate:field-groups --apply` was run without `--backup-confirmed`, so it changed nothing.

Applying the field-group storage migration renames tables and rewrites stored rows. It runs only once you state that a restorable backup of the database exists. A preview, without `--apply`, needs no backup.

## Fix

- Take a backup of the database you can restore from.
- Then run `nextly migrate:field-groups --apply --backup-confirmed`, adding `--down` to roll a migration back.

✗ `nextly migrate:field-groups --apply` did not run: it needs `--backup-confirmed`.
