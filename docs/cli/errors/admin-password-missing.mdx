---
title: ADMIN_PASSWORD_MISSING
description: "No password was given: `NEXTLY_ADMIN_PASSWORD` is not set and none was typed at a prompt."
---

## Cause

No password was given: `NEXTLY_ADMIN_PASSWORD` is not set and none was typed at a prompt.

The password is never taken from an argument, where it would stay in the shell's history. It comes from `NEXTLY_ADMIN_PASSWORD`, or from a prompt when the command runs in a terminal, and neither gave one.

## Fix

- In a script or CI, set `NEXTLY_ADMIN_PASSWORD` for the command: `NEXTLY_ADMIN_PASSWORD=… nextly users:create-admin --email ada@example.com --name Ada`.
- Or run the command in a terminal, where it asks for the password.
