---
title: MIGRATION_NAME_REQUIRED
description: "`nextly migrate:create` was given no name for a migration that is not blank."
---

## Cause

`nextly migrate:create` was given no name for a migration that is not blank.

A migration's name becomes part of its file name, so `nextly migrate:create` asks for one whenever it writes the changes from your configuration. Only an empty migration for hand-written SQL, made with `--blank`, may go without one.

## Fix

Name the migration, as a positional argument or with `--name`:

```bash
nextly migrate:create add_excerpt
nextly migrate:create --name=add_excerpt
```

Or pass `--blank` to create an empty migration for SQL you write yourself.
