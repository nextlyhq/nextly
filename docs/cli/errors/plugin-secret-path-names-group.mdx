---
title: PLUGIN_SECRET_PATH_NAMES_GROUP
description: "A plugin's secret path names a group of settings rather than one value."
---

## Cause

A plugin's secret path names a group of settings rather than one value.

A secret is one stored value, so its path must end at a single setting rather than a group of them.

## Fix

- Name the value inside the group, for example `provider.apiKey` rather than `provider`.

## Example

```text
✗ Plugin "reports" declares the secret path "provider", which names a group of settings rather than one value.
  Why:  A secret is one stored value, so its path ends at a single setting.
  Next: Name the value inside it.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-secret-path-names-group  (PLUGIN_SECRET_PATH_NAMES_GROUP)
```
