---
title: PACKAGE_INSTALL_FAILED
description: "The package manager could not install the package `nextly add` was given."
---

## Cause

The package manager could not install the package `nextly add` was given.

`nextly plugins add` (also run as `nextly add`) installs a plugin with the project's package manager (pnpm, yarn or npm) before it registers it. When that install fails, the command exits 1 before it changes anything else, like every other failed command, and names the package manager's own exit code in the message (`pnpm exited 254`). The package manager's own output, printed just above, says why.

## Fix

- Read the package manager's output above the error: a misspelled package name, a version it cannot resolve, or no network are the usual causes.
- Fix what it reports, then run `nextly plugins add <package>` again.
- If you installed the package another way, run `nextly plugins add <package> --skip-install` to register it without installing.

## Example

```text
✗ Install failed (pnpm exited 1).
  Why:  pnpm could not install `@nextlyhq/plugin-seo`; its own output above says why.
  Next: Fix what pnpm reports, then run `nextly plugins add @nextlyhq/plugin-seo` again.
  Docs: https://nextlyhq.com/docs/cli/errors/package-install-failed  (PACKAGE_INSTALL_FAILED)
```
