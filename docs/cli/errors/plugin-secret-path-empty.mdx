---
title: PLUGIN_SECRET_PATH_EMPTY
description: "A plugin declares an empty secret path."
---

## Cause

A plugin declares an empty secret path.

Each entry in `capabilities.secrets` names a setting by its dotted path in `contributes.settings`, and an empty one names nothing.

## Fix

- Remove the empty entry, or write the path of the setting it is for.

## Example

```text
✗ Plugin "reports" declares an empty secret path.
  Why:  Each entry in `capabilities.secrets` names a setting by its dotted path in `contributes.settings`.
  Next: Remove the empty entry from `capabilities.secrets`, or write the path of the setting it is for.
  Docs: https://nextlyhq.com/docs/cli/errors/plugin-secret-path-empty  (PLUGIN_SECRET_PATH_EMPTY)
```
