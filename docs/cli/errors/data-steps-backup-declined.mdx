---
title: DATA_STEPS_BACKUP_DECLINED
description: "A command would change data an earlier Nextly release stored, and its backup question was answered no."
---

## Cause

A command would change data an earlier Nextly release stored, and its backup question was answered no.

`nextly migrate`, `nextly db:sync` and `nextly i18n:convert-zoned-dates` rewrite values an earlier release stored, in place, so each asks whether the database is backed up before it changes anything. At the prompt the answer was no, so nothing was changed.

## Fix

- Back up the database.
- Run the command again and answer yes, or pass `--backup-confirmed`.

## Example

  Next: Back up the database, then run `nextly migrate` again and answer yes, or pass `--backup-confirmed`.
