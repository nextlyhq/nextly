## Start here

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
<Tab value="npm">
```bash
npx create-nextly-app@alpha my-app -y
cd my-app
npm run dev
```
</Tab>
<Tab value="pnpm">
```bash
pnpm create nextly-app@alpha my-app -y
cd my-app
pnpm dev
```
</Tab>
<Tab value="yarn">
```bash
yarn create nextly-app@alpha my-app -y
cd my-app
yarn dev
```
</Tab>
<Tab value="bun">
```bash
bun create nextly-app@alpha my-app -y
cd my-app
bun run dev
```
</Tab>
</Tabs>

1. **Create.** A project with the admin and a database.
2. **Start.** The first run creates the system tables.
3. **Sign in.** Open [http://localhost:3000/admin/setup](http://localhost:3000/admin/setup) and create the first admin.

`-y` takes the defaults: the blank template, SQLite and local storage. Leave it off to choose a template and a database. The [Quick start](/docs/getting-started/quick-start) goes through each step and what you should see.

Needs Node.js 22.12+ or 24+ (Node 24 LTS recommended), Next.js 16 with the App Router, React 19.

## Other ways in

- **An existing Next.js app.** Run `create-nextly-app` inside an existing Next.js app to add Nextly; it writes only the files the app does not have and extends the Next config. See [Add to an existing Next.js project](/docs/getting-started/installation#option-b-add-to-an-existing-nextjs-project).
- **With a coding agent.** Every new Nextly project ships with an AGENTS.md and CLAUDE.md written for coding agents. Agent skills for building with Nextly (installing it, collections, authentication, deploying) are published with each release: `npx skills add nextlyhq/nextly`. See [Coding agents](/docs/guides/coding-agents).
- **Learn the model first.** Model content in TypeScript or in the Visual Schema Builder. Both feed the same Nextly runtime, admin and APIs, with [the differences between them](/docs/schema-builder#builder-vs-code-first). See [Getting Started](/docs/getting-started) for collections, singles, fields and field groups.
