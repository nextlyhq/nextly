# widget-kit-fixture

A test fixture for the e2e suite, kept until the dev-only widget preview page can host these cards: widgets drawn by their own components (one built only from the plugin widget kit, one that throws, and one drawing an unlabelled control for the widget preview page's accessibility check), and widgets drawn by core's displays, among them one whose answer is always empty and whose widget hides when empty. The kit card and the full-width card declare preview cases, which the development widget preview page draws.
